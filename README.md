# AI Agent Skills

A collection of skills for AI coding agents (opencode / Claude Code).

| Skill | Description |
|---|---|
| `odoo-19` | Odoo 19 knowledge base (18 guides: controllers, decorators, SQL constraints, OWL, performance, ACL, testing) |
| `odoo` | Odoo ERP integration — connect, introspect, automate |
| `odoo-manager` | Manage Odoo via the External XML-RPC API (CRUD on any model) |
| `odoo-data-quality-gate` | Audit Odoo data quality (duplicates, missing required, orphaned references) |
| `ui-ux-pro-max` | UI/UX design intelligence (styles, palettes, font pairings, UX guidelines, icons) |
| `awesome-design-md` | DESIGN.md references from 73 real websites (Airbnb, Apple, Claude, Figma, Linear, Notion...) |
| `frontend-design` | Guidance for distinctive, intentional visual design |
| `postgres-patterns` | PostgreSQL patterns (query optimization, schema, indexing, RLS) |
| `python-patterns` | Pythonic idioms, PEP 8, type hints, best practices |
| `python-testing` | pytest strategies (TDD, fixtures, mocking, coverage) |
| `python-debugpy` | Debug Python (pdb, breakpoint(), debugpy remote attach) |
| `learn-python` | Learn Python (Chinese) |
| `learn-cpp` | Learn C++ (Chinese) |
| `learn-java` | Learn Java (Chinese) |

## Install

Copy the skill folder(s) into your agent's skills directory:

- opencode: `~/.agents/skills/`
- Claude Code: `~/.claude/skills/`
