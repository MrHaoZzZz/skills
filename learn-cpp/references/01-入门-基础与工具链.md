# C++ 入门 · 基础与工具链

## 1. 什么是 C++

C++ 是一门「编译型」「静态类型」「多范式」语言，由 Bjarne Stroustrup 在 C 基础上发展而来。核心哲学：**零开销抽象（zero-overhead abstraction）**——高级抽象不额外消耗运行时性能，因为你直接掌控内存布局与资源。

类比：C++ 像一台手动挡汽车，功能强大、效率高，但换挡（内存管理）需要你自己操作；Python/Java 是自动挡，省心但牺牲了一些控制力。

### 这门语言能做什么？从黑框到图形界面

你之前一直在「黑框」（terminal）里跑程序，可能会疑惑：这怎么变成窗口和按钮？

**关键认知**：所有程序本质都是「输入 → 处理 → 输出」。黑框程序 = 输入键盘 + 输出字符到终端；图形程序 = 输入鼠标/键盘事件 + 输出「调用操作系统 API 画窗口」。**变的只是输出这一环，你的处理逻辑（算法、数据结构）完全不变。**

C++ 在现实世界的主战场：
- **游戏引擎**：Unreal、Cocos（图形化的极致应用）
- **桌面软件**：Qt（跨平台 GUI 主力）、ImGui（游戏/工具即时界面）
- 浏览器内核（Chrome）、操作系统、数据库内核、音视频编解码、量化交易

C++ 写图形界面最主流是 **Qt**（需额外安装 Qt SDK）。一个 Qt 窗口的最小示例：

```cpp
#include <QApplication>
#include <QLabel>
int main(int argc, char* argv[]) {
    QApplication app(argc, argv);
    QLabel label("Hello, GUI!");   // 一个显示文字的窗口
    label.show();
    return app.exec();             // 进入事件循环
}
```

> 初学阶段先用黑框掌握语言本身，图形化放到掌握「类/对象/STL」之后（Qt 大量用到面向对象）。**建议路径**：先学完本 skill 的入门~进阶（OOP 之后）→ 再单独学 Qt，随时可以问我。

## 2. 工具链：从源码到可执行文件

编译型语言的完整流程（对比解释型语言直接运行）：

```
源码 .cpp ──预处理(preprocess)──> 展开宏/头文件
          ──编译(compile)──────> 目标文件 .o（机器码）
          ──链接(link)─────────> 可执行文件
```

关键工具：
- **编译器**：`g++`（GCC）或 `clang++`（Clang）。
- **构建系统**：单文件可直接编译，多文件用 `cmake` + `make`（工程阶段细讲）。

### 第一个程序

```cpp
#include <iostream>   // 头文件：引入输入输出流

int main() {                       // 程序入口，必须返回 int
    std::cout << "Hello, C++\n";   // 输出到标准输出
    return 0;                       // 0 表示成功
}
```

编译运行：

```bash
g++ -std=c++17 main.cpp -o hello   # -std 指定标准版本
./hello                            # macOS/Linux 运行
# Windows 运行：hello.exe
```

**术语**：`main` 是入口函数（entry point）；`std::` 是命名空间（namespace）前缀，`std::cout` 表示标准库里的输出流。

## 3. 基础类型与变量

C++ 是静态类型：**变量类型在编译期确定，不可改变**。

| 类型 | 含义 | 大小(典型) | 示例 |
|------|------|-----------|------|
| `int` | 整数 | 4 字节 | `int a = 42;` |
| `double` | 双精度浮点 | 8 字节 | `double pi = 3.14;` |
| `float` | 单精度浮点 | 4 字节 | `float f = 1.5f;` |
| `char` | 字符 | 1 字节 | `char c = 'A';` |
| `bool` | 布尔 | 1 字节 | `bool ok = true;` |
| `long long` | 大整数 | 8 字节 | `long long n = 1e9;` |
| `unsigned int` | 无符号整数 | 4 字节 | `unsigned int u = 5;` |
| `size_t` | 无符号整数，用于大小/下标 | 8 字节 | `size_t i = 0;` |

```cpp
int age = 30;          // 初始化（推荐写法）
double score{9.5};     // 列表初始化，更安全（会阻止窄化转换）
auto name = "cpp";     // auto：自动类型推导（现代 C++ 推荐）
```

**易错点**：`unsigned` 类型永远 >= 0，做减法可能「下溢」变成巨大数字。避免无符号整数参与运算，除非确实需要。

## 4. 控制流

### 条件

```cpp
if (age >= 18) {
    std::cout << "adult\n";
} else if (age >= 13) {
    std::cout << "teen\n";
} else {
    std::cout << "child\n";
}

// switch 只能用于整型/枚举/字符
switch (day) {
    case 1: std::cout << "Mon\n"; break;
    case 2: std::cout << "Tue\n"; break;
    default: std::cout << "other\n";
}
```

### 循环

```cpp
for (int i = 0; i < 10; ++i) { ... }        // 传统 for
for (int x : vec) { ... }                    // 范围 for（range-based，现代 C++）

while (cond) { ... }
do { ... } while (cond);                     // 至少执行一次
```

**惯用法**：优先用范围 `for` 遍历容器；用 `++i` 而非 `i++`（对简单 int 无差别，但对迭代器更高效）。

## 5. 函数

```cpp
// 返回类型 + 函数名 + 参数列表
int add(int a, int b) {
    return a + b;
}

// 传值 vs 传引用（C++ 重点，进阶细讲）
void byValue(int x)   { x = 100; }   // 修改的是副本，不影响调用者
void byRef(int& x)    { x = 100; }   // 修改的是原变量本身

int main() {
    int v = 1;
    byValue(v);  // v 仍为 1
    byRef(v);    // v 变为 100
}
```

**关键概念**：`&` 在参数类型里表示「引用（reference）」，是原变量的别名，不是副本。

## 6. 数组与 std::string

### 原始数组（C 风格，尽量少用）

```cpp
int arr[5] = {1, 2, 3, 4, 5};   // 固定大小，编译期确定
// 无法直接知道长度，容易越界
```

### 现代替代：std::string 与 std::vector（进阶细讲）

```cpp
#include <string>
std::string s = "hello";
s += " world";                    // 拼接
std::cout << s.length() << '\n';  // 长度
```

> 入门阶段即可直接用 `std::string`，不要手动管理 C 风格字符串 `char[]`。

## 7. 输入输出

```cpp
#include <iostream>
int age;
std::cin >> age;                     // 读取输入
std::cout << "age = " << age << '\n'; // 输出（'\n' 比 std::endl 高效，endl 会额外刷新缓冲）
```
