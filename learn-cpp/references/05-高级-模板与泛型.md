# C++ 高级 · 模板与泛型编程

模板（template）是 C++ 的「编译器驱动的代码生成器」——一次编写，按需为不同类型生成代码。STL 就是靠模板实现的。

## 1. 函数模板

```cpp
// 不再为 int、double 各写一遍
template <typename T>
T max(T a, T b) {
    return a > b ? a : b;
}

int main() {
    max(1, 2);            // T 推导为 int
    max(1.5, 2.5);        // T 推导为 double
    max<int>(1, 2);       // 显式指定类型
}
```

**原理**：编译期实例化（instantiation）——编译器为用到的每个类型生成一份具体代码。这是「零开销」的来源：泛型在运行时无额外成本。

## 2. 类模板

```cpp
template <typename T>
class Stack {
    std::vector<T> data_;
public:
    void push(T value) { data_.push_back(value); }
    T top() const { return data_.back(); }
};

Stack<int> si;
Stack<std::string> ss;
```

## 3. 模板特化（specialization）

为特定类型提供专门实现。

```cpp
template <typename T>
T identity(T x) { return x; }

// 全特化：T 是 char* 时用这个版本
template <>
const char* identity<const char*>(const char* x) { return x; }
```

## 4. 变参模板（variadic templates）

C++11 起支持任意数量模板参数。

```cpp
// 递归展开参数包
void print() {}   // 递归终止

template <typename T, typename... Args>
void print(T first, Args... rest) {
    std::cout << first << ' ';
    print(rest...);   // 递归调用，参数包递减
}
```

## 5. 模板元编程与类型萃取（type traits）

`<type_traits>` 提供编译期类型判断与转换。

```cpp
#include <type_traits>
static_assert(std::is_integral<int>::value);       // 编译期断言
static_assert(std::is_same<int, int32_t>::value);

// SFINAE：根据类型启用不同重载
template <typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
process(T x) { return x * 2; }
```

## 6. C++20 concepts（概念）

给模板参数加「约束」，让报错更友好、意图更清晰。

```cpp
#include <concepts>

template <typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template <Numeric T>          // 只有满足 Numeric 才能用
T add(T a, T b) { return a + b; }
```

对比传统 `typename`：concepts 在**编译期**就清晰报错「约束不满足」，而非在深层的实例化错误里让人抓狂。

## 7. constexpr（编译期计算）

```cpp
constexpr int square(int x) { return x * x; }

constexpr int result = square(5);   // 编译期算出 25，写进常量
int arr[square(3)];                 // 可作数组大小
```

`constexpr` 函数在编译期执行，减少运行时开销；`consteval`（C++20）则强制编译期。

## 8. 异常安全（exception safety）

写模板和库代码时要考虑异常下的资源安全。三个保证级别：

1. **基本保证**：异常时不泄漏资源、对象仍可析构。
2. **强保证**：异常时状态完全不变（要么成功要么原样）。
3. **不抛异常保证**：`noexcept` 标记，绝不抛出。

```cpp
void f() noexcept {   // 承诺不抛异常
    // ...
}
```

**关键点**：移动构造/移动赋值尽量标 `noexcept`，否则 `std::vector` 扩容时会退化为拷贝（因为要保证强异常安全）。
