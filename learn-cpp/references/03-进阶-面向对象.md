# C++ 进阶 · 面向对象

## 1. 类与对象

**类（class）是蓝图，对象（object）是实例**。类封装数据（成员变量）和行为（成员函数）。

```cpp
#include <string>

class Person {
public:                       // 公开接口
    Person(std::string name, int age)   // 构造函数（名字与类名相同）
        : name_(name), age_(age) {}     // 成员初始化列表（推荐写法）

    void introduce() const {  // const 表示不修改成员变量
        std::cout << name_ << ", " << age_ << " years old\n";
    }

    int age() const { return age_; }   // getter

private:                      // 封装：外部不可访问
    std::string name_;
    int age_;
};

int main() {
    Person p("Alice", 30);   // 栈上创建
    p.introduce();

    // 成员变量命名习惯：加下划线后缀 name_
}
```

### 关键点
- **访问控制**：`public`（对外）/`private`（仅类内）/`protected`（类内+派生类）。
- **构造函数（constructor）**：创建对象时自动调用，负责初始化。
- **析构函数（destructor）**：`~Person()`，对象销毁时自动调用，负责清理资源（RAII 的关键）。
- **成员初始化列表**：`: name_(name)`，比在函数体里赋值更高效（尤其对 `const`/引用成员）。
- **const 成员函数**：承诺不改成员，可在 const 对象上调用。

## 2. 封装、继承、多态（OOP 三要素）

### 封装（Encapsulation）
数据私有，通过公开方法访问，隐藏内部实现，保护不变式（invariant）。

### 继承（Inheritance）
派生类复用并扩展基类。

```cpp
class Animal {
public:
    virtual void speak() const {        // virtual：可被覆写
        std::cout << "?\n";
    }
    virtual ~Animal() = default;        // 基类析构必须 virtual！
};

class Dog : public Animal {             // public 继承：Dog 是 Animal
public:
    void speak() const override {       // override：覆写基类虚函数
        std::cout << "Woof\n";
    }
};
```

### 多态（Polymorphism）
通过基类指针/引用调用派生类方法，运行时决定调用哪个版本。

```cpp
Animal* a = new Dog();
a->speak();       // 输出 "Woof"（因为 speak 是虚函数）
delete a;         // 基类析构是 virtual，正确调用 Dog 的析构
```

**关键规则**：
- 想要多态 → 基类方法声明 `virtual`，派生类加 `override`。
- **基类析构函数必须 `virtual`**，否则通过基类指针 `delete` 派生对象时不会调用派生类析构，导致资源泄漏。

## 3. 构造/析构的完整流程

```cpp
class B : public A {
public:
    B() { std::cout << "B ctor\n"; }
    ~B() { std::cout << "B dtor\n"; }
};
// 创建 B 对象：先构造 A（基类），再构造 B 的成员，再 B 自身
// 销毁 B 对象：先析构 B，再析构成员，再析构 A（顺序相反）
```

## 4. 运算符重载

让自定义类型支持 `+`、`==`、`<<` 等运算符。

```cpp
class Vector2 {
public:
    double x, y;
    Vector2(double x, double y) : x(x), y(y) {}

    Vector2 operator+(const Vector2& other) const {
        return Vector2(x + other.x, y + other.y);
    }
};

// 流输出运算符（作为自由函数，friend 或调用公有接口）
std::ostream& operator<<(std::ostream& os, const Vector2& v) {
    return os << "(" << v.x << ", " << v.y << ")";
}
```

## 5. 三大特殊成员函数（Rule of Three / Five）

编译器会默认生成：构造、析构、拷贝构造、拷贝赋值、（C++11 起）移动构造、移动赋值。

**Rule of Five**：如果自定义了其中任一（通常是管理堆资源），通常需要自定义全部五个（或全部删除）。

```cpp
class Buffer {
public:
    Buffer(size_t n) : data(new char[n]), size(n) {}

    ~Buffer() { delete[] data; }                    // 1 析构

    Buffer(const Buffer& other)                     // 2 拷贝构造（深拷贝）
        : data(new char[other.size]), size(other.size) {
        std::copy(other.data, other.data + size, data);
    }

    Buffer& operator=(const Buffer& other) {        // 3 拷贝赋值
        if (this == &other) return *this;           // 防自赋值
        delete[] data;
        size = other.size;
        data = new char[size];
        std::copy(other.data, other.data + size, data);
        return *this;
    }

    Buffer(Buffer&& other) noexcept                 // 4 移动构造（转移资源）
        : data(other.data), size(other.size) {
        other.data = nullptr;                       // 置空源对象
    }

    Buffer& operator=(Buffer&& other) noexcept {    // 5 移动赋值
        if (this == &other) return *this;
        delete[] data;
        data = other.data;
        size = other.size;
        other.data = nullptr;
        return *this;
    }

private:
    char* data;
    size_t size;
};
```

> 但这正是**为什么推荐用 `std::vector`/`std::string`/智能指针**——它们已实现好这些，你无需手写拷贝/移动。

## 6. 组合优先于继承

能用「有一个」（组合）就别用「是一个」（继承）。继承耦合度高，只在确有 is-a 关系且需要多态时使用。

```cpp
class Car {
    Engine engine_;    // 组合：Car 有一个 Engine
    // 而非 class Car : public Engine  （错误：Car 不是一个 Engine）
};
```
