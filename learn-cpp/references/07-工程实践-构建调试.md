# C++ 工程实践 · 现代特性、构建与调试

## 1. 现代 C++ 演进速览

| 标准 | 年份 | 里程碑特性 |
|------|------|-----------|
| C++11 | 2011 | auto、智能指针、移动语义、lambda、并发、range-for |
| C++14 | 2014 | 泛型 lambda、`make_unique` |
| C++17 | 2017 | 结构化绑定、if constexpr、`std::optional`、`std::variant`、并行算法 |
| C++20 | 2020 | concepts、ranges、协程(coroutine)、模块(modules)、三路比较 `<=>` |
| C++23 | 2023 | `std::expected`、更多 ranges 优化 |

**建议**：学习以 C++17 为基线，重点掌握 C++11 的移动语义、C++20 的 concepts。

### 常用现代特性示例

```cpp
// 结构化绑定（C++17）
std::pair<int, std::string> p{1, "one"};
auto [num, str] = p;          // 直接拆解

// std::optional（C++17）：可能没有值
#include <optional>
std::optional<int> find(int key) {
    if (key == 0) return std::nullopt;
    return key * 2;
}

// if constexpr（C++17）：编译期分支
template <typename T>
void show(T v) {
    if constexpr (std::is_integral<T>::value)
        std::cout << "int: " << v;
    else
        std::cout << "other: " << v;
}
```

## 2. 项目结构与 CMake

### 单文件（入门）

```bash
g++ -std=c++17 -Wall -Wextra -O2 main.cpp -o main
```

### 多文件项目用 CMake

```
myproject/
  CMakeLists.txt
  src/
    main.cpp
    utils.cpp
  include/
    utils.h
```

`CMakeLists.txt`：

```cmake
cmake_minimum_required(VERSION 3.15)
project(MyProject CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

add_executable(myapp src/main.cpp src/utils.cpp)
target_include_directories(myapp PRIVATE include)
```

构建：

```bash
cmake -S . -B build
cmake --build build
./build/myapp          # macOS/Linux
# Windows 运行：build\myapp.exe（或 build\Debug\myapp.exe，取决于生成器）
```

## 3. 编译警告与优化

```bash
# 警告全开（务必养成习惯）
g++ -Wall -Wextra -Wpedantic main.cpp

# 优化级别：-O0(默认，调试) -O2(常规) -O3(激进) -Os(体积)
g++ -O2 main.cpp

# 调试信息（配合 gdb）
g++ -g main.cpp -o main
```

## 4. 调试工具

### gdb 基本流程

```bash
gdb ./main
(gdb) break main          # 断点
(gdb) run                 # 运行
(gdb) next                # 单步（不进入函数）
(gdb) step                # 单步（进入函数）
(gdb) print var           # 查看变量
(gdb) backtrace           # 查看调用栈
(gdb) continue            # 继续
(gdb) quit
```

### 内存/UB 检查（sanitizers，强烈推荐）

编译器内置的内存错误检测器，学习期务必多用：

```bash
# 地址消毒：检测越界、use-after-free、内存泄漏
g++ -fsanitize=address -g main.cpp -o main && ./main

# 未定义行为消毒
g++ -fsanitize=undefined -g main.cpp -o main && ./main
```

**价值**：`-fsanitize=address` 能精准报出「哪一行」越界/泄漏，是理解内存错误的利器。

## 5. 性能分析

```bash
# 简单计时
time ./main

# 性能剖析（macOS 用 Instruments，Linux 用 perf/gprof）
g++ -pg main.cpp -o main && ./main && gprof main
```

## 6. 头文件与编译单元

```cpp
// utils.h —— 声明放头文件
#pragma once                    // 防止重复包含（或 include guard）
int add(int a, int b);

// utils.cpp —— 定义放源文件
#include "utils.h"
int add(int a, int b) { return a + b; }
```

**规则**：
- 头文件只放声明（模板/内联函数除外，因为它们需要编译期可见）。
- `#pragma once` 或 include guard 防重复包含。
- 不要在头文件里 `using namespace std`。
