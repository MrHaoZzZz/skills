# C++ 巩固 · 常见错误与综合练习

## 1. 高频易错点 Top 10

### 1. 悬垂指针 / 悬垂引用

```cpp
int* p = &local();      // 错：返回局部变量地址
// 正确：不要返回局部变量的地址/引用
```

### 2. 忘记释放 / 双重释放

```cpp
int* p = new int;
delete p;
delete p;     // 错！双重释放（double free）
```

### 3. `new[]` 配 `delete`（应为 `delete[]`）

```cpp
int* arr = new int[10];
delete arr;   // 错！应为 delete[] arr
```

### 4. 基类析构非 virtual

```cpp
Animal* a = new Dog();
delete a;     // 若 ~Animal() 非 virtual，只析构 Animal 部分 → 泄漏
```

### 5. 忽略返回值 / 未初始化变量

```cpp
int x;                 // 未初始化，读它是 UB
std::vector<int> v;
v[0];                  // 错！越界（v 为空），应用 v.at(0) 或先判断
```

### 6. 有符号/无符号混用

```cpp
for (unsigned i = v.size() - 1; i >= 0; --i)  // 错！i 无符号，i>=0 恒真 → 死循环
```

### 7. 迭代器失效

```cpp
for (auto it = v.begin(); it != v.end(); ++it)
    if (bad(*it)) v.erase(it);   // 错！erase 使 it 失效
// 正确：it = v.erase(it);
```

### 8. 按值传递大对象导致拷贝

```cpp
void f(std::vector<int> v);       // 每次调用拷贝整个 vector
void f(const std::vector<int>& v); // 正确：const 引用，零拷贝
```

### 9. `using namespace std` 进头文件

```cpp
// 头文件里不要写 using namespace std —— 污染全局
// 正确：std:: 前缀
```

### 10. 自赋值未检查（手写赋值运算符时）

```cpp
Buffer& operator=(const Buffer& o) {
    if (this == &o) return *this;   // 必须检查自赋值
    ...
}
```

## 2. 未定义行为（UB）速查

UB 是最危险的错误：编译器可能「看似正常」，但结果不可预测。

- 解引用空指针/野指针
- 数组越界（读或写）
- 有符号整数溢出（`INT_MAX + 1`）
- 读未初始化变量
- 双重释放 / use-after-free
- 数据竞争

**对策**：编译开 `-Wall -Wextra`，运行加 `-fsanitize=address,undefined`。

## 3. 综合练习（由易到难）

### 练习 A：字符串处理
实现一个函数，反转 `std::string`，并统计元音字母数量。分别用索引、迭代器、范围 for 实现一遍。

### 练习 B：动态数组封装
自己实现一个简易 `MyVector` 类：支持 `push_back`、`size`、`operator[]`、拷贝/移动语义，内部用 `new[]` 管理动态数组。重点体会 Rule of Five 和扩容逻辑。

### 练习 C：泛型排序
写一个模板函数，用 `std::sort` + 自定义比较器，对一个 `vector` 按多种规则排序（如按名字升序、按年龄降序）。

### 练习 D：多线程计数
开 4 个线程各累加 25 万次到共享计数器，分别用 mutex 和 atomic 实现，对比结果正确性。

### 练习 E：小项目
实现一个命令行「学生成绩管理」：用 `map` 存姓名→成绩，支持增删查、排序输出、平均分计算，拆成多文件 + CMake 构建。
