# Python 巩固 · 常见错误与综合练习

## 1. 高频易错点 Top 10

### 1. 可变默认参数

```python
# ❌ 错：默认参数只创建一次，list 被共享
def append_to(item, items=[]):
    items.append(item)
    return items

append_to(1)   # [1]
append_to(2)   # [1, 2]！不是 [2]

# ✅ 对：用 None + 每次新建
def append_to(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

### 2. 浅拷贝 vs 深拷贝

```python
import copy
a = [[1, 2], [3, 4]]
b = a.copy()         # 浅拷贝：内层列表仍是同一对象
b[0].append(9)       # a[0] 也变成 [1,2,9]！

c = copy.deepcopy(a) # 深拷贝：完全独立
```

### 3. 用 `==` 判断 None

```python
if x == None:    # ❌ 应写成 is None
if x is None:    # ✅
```

### 4. 修改列表的同时遍历它

```python
for x in lst:
    if bad(x):
        lst.remove(x)   # ❌ 会跳过元素
# ✅ 用新列表或反向遍历或 list comprehension
lst = [x for x in lst if not bad(x)]
```

### 5. 作用域混淆（局部 vs 全局）

```python
count = 0
def f():
    count = 5      # 创建了局部变量，不是修改全局

def g():
    global count   # 明确声明才能改全局
    count = 5
```

### 6. 字符串拼接性能

```python
# ❌ 循环中 += 字符串，O(n²)
result = ""
for x in items:
    result += x

# ✅ 用 join
result = "".join(items)
```

### 7. 除法的坑（Python 2 vs 3）

```python
5 / 2    # 2.5（Python 3 是浮点除法）
5 // 2   # 2（整除）
5 % 2    # 1
```

### 8. 布尔值也是 int

```python
True == 1    # True（Python 里 bool 是 int 子类）
```

### 9. 迭代时修改 dict

```python
for k in d:
    del d[k]        # ❌ RuntimeError: dictionary changed size
# ✅ 遍历 list(d) 或 list(d.keys())
```

### 10. 闭包晚绑定

```python
funcs = [lambda: i for i in range(3)]
funcs[0]()   # 2！不是 0（变量 i 最后是 2）
# ✅ 用默认参数捕获当前值
funcs = [lambda i=i: i for i in range(3)]
```
