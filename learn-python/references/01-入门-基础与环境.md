# Python 入门 · 基础与环境

## 1. 什么是 Python

Python 是一门**解释型、动态类型、多范式**语言，设计哲学是「优雅、明确、简单」（`import this` 可看 Zen of Python）。相比 C++ 的「手动挡」，Python 是「自动挡」——省去类型声明和内存管理，专注解决问题本身。

**与 C++ 的关键差异**：
- 解释执行，无需编译，改完即可运行。
- 动态类型：变量类型运行时确定，无需声明。
- 自动内存管理（引用计数 + GC），无指针、无 `new`/`delete`。

### 这门语言能做什么？从黑框到图形界面

你之前一直在「黑框」（terminal）里跑程序，可能会疑惑：这怎么变成窗口和网页？

**关键认知**：所有程序本质都是「输入 → 处理 → 输出」。黑框程序 = 输入键盘 + 输出字符；图形程序 = 输入鼠标事件 + 输出「调用 GUI 库画界面」。**变的只是输出这一环，处理逻辑完全不变。**

Python 在现实世界的主战场：
- **AI/机器学习**：PyTorch、scikit-learn
- **数据科学**：Pandas、NumPy
- **Web 后端**：FastAPI、Django（配前端网页形成界面）
- 自动化脚本、爬虫、运维工具

Python 写图形界面最快，用标准库自带的 **Tkinter**（无需安装任何东西）：

```python
import tkinter as tk
root = tk.Tk()
def on_click():
    label.config(text=f"3+4={3+4}")   # 处理逻辑就是你熟悉的那部分
tk.Button(root, text="点我", command=on_click).pack()
label = tk.Label(root, text="")
label.pack()
root.mainloop()   # 进入事件循环
```

> **建议路径**：Python 是最适合「从黑框迈向图形化」的起点——Tkinter 零依赖立刻能跑，还能快速进阶到 Web 后端（FastAPI）。先跑通上面的窗口，建立「点按钮 → 触发逻辑 → 显示结果」的直觉。

## 2. 环境与虚拟环境

```bash
python3 --version          # 检查版本（建议 3.10+），Windows 用 python --version

# 虚拟环境：每个项目独立隔离依赖（工程必用）
# macOS / Linux：
python3 -m venv .venv
source .venv/bin/activate

# Windows（PowerShell 或 CMD）：
python -m venv .venv
.venv\Scripts\activate

deactivate                # 退出（两平台通用）
```

**为什么用 venv**：不同项目依赖不同版本的库，全局装会冲突。每个项目一个 `.venv`，干净隔离。

## 3. 第一个程序

```python
print("Hello, Python")   # print 是内置函数，无需 main
```

运行：

```bash
python3 hello.py
# 或直接在解释器里交互式输入
python3
>>> print("hi")
```

**注意**：Python 没有 `main` 函数（有 `if __name__ == "__main__":` 的惯例，进阶讲）。缩进就是代码块，**不是花括号**。

## 4. 基础类型与变量

```python
age = 30            # int
score = 9.5         # float
name = "Alice"      # str
ok = True           # bool
nothing = None      # NoneType（相当于 null）

# 动态类型：变量类型可随时变
x = 10
x = "now a string"  # 合法
```

### 常用类型

| 类型 | 示例 | 说明 |
|------|------|------|
| `int` | `42` | 任意精度整数（不像 C++ 会溢出）|
| `float` | `3.14` | 浮点 |
| `str` | `"hello"` | 字符串（不可变）|
| `bool` | `True`/`False` | 布尔 |
| `None` | `None` | 空值 |
| `list` | `[1, 2, 3]` | 可变列表 |
| `tuple` | `(1, 2)` | 不可变元组 |
| `dict` | `{"a": 1}` | 字典 |
| `set` | `{1, 2, 3}` | 集合 |

```python
# 类型判断与转换
type(age)          # <class 'int'>
int("123")         # 字符串转 int
str(123)           # int 转字符串
float("3.14")      # 转 float
```

## 5. 控制流

```python
# 条件（靠缩进，无花括号）
if age >= 18:
    print("adult")
elif age >= 13:
    print("teen")
else:
    print("child")

# 循环
for i in range(10):        # 0..9
    print(i)

for x in [1, 2, 3]:        # 直接遍历元素（Pythonic）
    print(x)

while cond:
    ...

# break / continue 同 C++
```

**惯用法**：Python 几乎不用索引循环 `for i in range(len(x))`，直接 `for x in items`。

## 6. 字符串

```python
s = "hello"
len(s)                  # 5
s.upper()               # "HELLO"
s.lower()               # "hello"
s.capitalize()          # "Hello"
s.strip()               # 去首尾空白
s.split(",")            # 按分隔符切分 → list
",".join(["a", "b"])    # 拼接 → "a,b"
"world" in s            # 是否包含 → False

# f-string（最常用格式化，Python 3.6+）
name = "Alice"
print(f"Hello, {name}!")   # Hello, Alice!

# 切片（slicing）
s = "hello"
s[0]        # 'h'
s[1:4]      # 'ell'（左闭右开）
s[::-1]     # 'olleh'（反转）
```

## 7. 函数

```python
def add(a, b):
    return a + b

# 默认参数、关键字参数
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}"

greet("Alice")                    # 位置参数
greet("Alice", greeting="Hi")     # 关键字参数

# 返回值可多个（实际是返回 tuple）
def divmod2(a, b):
    return a // b, a % b

q, r = divmod2(10, 3)   # 解包
```

**易错点**：默认参数**不要用可变对象**（见「常见错误」章节）。
