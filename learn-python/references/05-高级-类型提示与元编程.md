# Python 高级 · 类型提示与元编程

## 1. 类型提示（type hints）

Python 动态类型灵活，但大型项目需要类型提示提升可读性和工具支持（不强制，但强烈推荐）。

```python
from typing import Optional, List, Dict, Union

def greet(name: str, age: int = 0) -> str:
    return f"{name}, {age}"

def find_user(id: int) -> Optional[User]:      # 可能返回 None
    ...

def process(items: List[int]) -> Dict[str, int]:
    ...

# 现代写法（Python 3.9+ 用内置泛型，无需 typing.List）
def process(items: list[int]) -> dict[str, int]:
    ...

# 联合类型（Python 3.10+ 用 |）
def parse(x: str | int) -> float:
    ...
```

### 变量类型注解

```python
from typing import TypeVar
T = TypeVar('T')

def first(items: list[T]) -> T | None:
    return items[0] if items else None
```

### 与 C++/Java 的对比

- Python 类型提示**运行时不检查**（只是注解），靠工具（mypy/pyright/IDE）静态检查。
- 类似 C++ 模板的 `TypeVar`，但更宽松。

### 工具

```bash
pip install mypy
mypy your_file.py        # 静态类型检查
```

## 2. 异常处理

```python
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"错误：{e}")
except (ValueError, TypeError) as e:
    print("多个异常")
else:
    print("没异常时执行")
finally:
    print("无论如何都执行")

# 抛异常
def check(age):
    if age < 0:
        raise ValueError("age must be >= 0")

# 自定义异常
class AppError(Exception):
    pass
```

**与 C++ 的差异**：Python 异常很便宜，是「请求宽恕比请求许可更容易」（EAFP）——先尝试，失败再处理，而非先检查。

```python
# EAFP（Pythonic）
try:
    value = d[key]
except KeyError:
    value = default

# LBYL（C++/Java 风格，不推荐）
if key in d:
    value = d[key]
```

## 3. 元编程与元类（metaclass）

元类是「**创建类的类**」——`type` 就是默认元类。这是 Python 的高级能力，框架（ORM 等）常用，业务代码少用。

```python
# 动态创建类
MyClass = type("MyClass", (Base,), {"attr": 42})

# 自定义元类
class Meta(type):
    def __new__(cls, name, bases, dct):
        dct["version"] = 1.0        # 给所有用此元类的类加属性
        return super().__new__(cls, name, bases, dct)

class A(metaclass=Meta):
    pass

A.version   # 1.0
```

### 更常用的元编程：装饰器 + `__getattr__`/`__setattr__`

```python
class LazyAttributes:
    def __getattr__(self, name):
        # 访问不存在的属性时触发
        return f"计算出的 {name}"

obj = LazyAttributes()
obj.anything   # "计算出的 anything"
```

## 4. 描述符与 property 进阶

```python
class Validated:
    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, owner):
        return obj.__dict__.get(self.name)

    def __set__(self, obj, value):
        if value < 0:
            raise ValueError("不能为负")
        obj.__dict__[self.name] = value

class Order:
    quantity = Validated()   # 描述符：属性访问的底层机制
```

## 5. `__slots__` 与内存优化

```python
class Point:
    __slots__ = ['x', 'y']   # 禁用 __dict__，节省内存
    def __init__(self, x, y):
        self.x, self.y = x, y
```

大量小对象时 `__slots__` 可显著省内存（类似 C++ 里不用虚函数/动态字典）。
