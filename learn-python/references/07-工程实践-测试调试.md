# Python 工程实践 · 测试、打包与调试

## 1. 虚拟环境与依赖管理

```bash
# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

# Windows（PowerShell 或 CMD）
python -m venv .venv
.venv\Scripts\activate

# 依赖管理（现代工具）
pip install requests
pip freeze > requirements.txt      # 导出依赖
pip install -r requirements.txt    # 安装依赖

# 更现代的工具（推荐了解）
# poetry / uv / pipenv —— 更好的依赖解析和锁文件
```

## 2. 项目结构

```
myproject/
  src/mypackage/
    __init__.py
    core.py
    utils.py
  tests/
    test_core.py
    test_utils.py
  pyproject.toml        # 项目元数据 + 工具配置
  README.md
  .gitignore
```

`pyproject.toml` 是现代 Python 项目的标准配置文件（打包、格式化、类型检查、pytest 都配在这里）。

## 3. 单元测试（pytest）

> 你本地已有 `python-testing` skill，这里只讲入门，深入可加载它。

```python
# tests/test_calc.py
def test_add():
    assert add(2, 3) == 5

def test_divide_by_zero():
    import pytest
    with pytest.raises(ZeroDivisionError):
        divide(1, 0)
```

```bash
pip install pytest
pytest                    # 自动发现 tests/
pytest -v                 # 详细输出
pytest --cov=mypackage    # 覆盖率（需 pytest-cov）
```

**价值**：测试意识是工程化的核心。尤其你有算法底子，为每个函数写「边界 + 典型 + 异常」测试是天然优势。

## 4. 代码质量工具

```bash
pip install ruff mypy

ruff check .              # 代码检查（lint，快，替代 flake8）
ruff format .             # 格式化（替代 black）

mypy .                    # 类型检查

# 或用 black/isort
black .
isort .
```

统一工具配置写进 `pyproject.toml`，保证团队风格一致。

## 5. 调试

> 你本地已有 `python-debugpy` skill，深入可加载它。

### 快速调试：print 与 pdb

```python
# 就地打断点
breakpoint()              # Python 3.7+，进入 pdb 调试器

# 或命令行
python3 -m pdb script.py
```

### pdb 常用命令

```
n       # next：单步
s       # step：进入函数
c       # continue：继续
p expr  # 打印表达式
l       # 查看源码
q       # 退出
```

### 日志（logging，工程推荐替代 print）

```python
import logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

logger.info("处理中")
logger.error("出错了", exc_info=True)
```

## 7. 性能优化

```python
# 计时
import time
start = time.perf_counter()
... 
elapsed = time.perf_counter() - start

# 性能剖析
python3 -m cProfile -s cumulative script.py
```

**优化思路**：先剖析找到瓶颈（通常是少量热点代码），再针对性优化，不要盲目优化。
