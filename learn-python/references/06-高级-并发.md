# Python 高级 · 并发与异步

Python 并发有三套模型，适用场景不同，这是很多人的困惑点。

## 1. 先搞清楚：GIL（全局解释器锁）

CPython（标准实现）有 **GIL**：同一时刻只有一个线程执行 Python 字节码。所以：

- **CPU 密集型**任务：多线程**无法**加速（甚至更慢），要用**多进程**。
- **I/O 密集型**任务（网络、文件、等待）：多线程/异步**可以**大幅提速（因为等待时释放 GIL）。

```python
import threading
print(threading.active_count())
```

**关键结论**：选并发模型前，先判断任务是 CPU 密集还是 I/O 密集。

## 2. 多线程（threading）—— I/O 密集

```python
import threading
import time

def fetch(url):
    time.sleep(1)          # 模拟 I/O 等待
    return url

threads = []
for i in range(10):
    t = threading.Thread(target=fetch, args=(f"url{i}",))
    threads.append(t)
    t.start()

for t in threads:
    t.join()               # 等所有线程结束
```

### 线程池（推荐）

```python
from concurrent.futures import ThreadPoolExecutor

with ThreadPoolExecutor(max_workers=10) as pool:
    results = list(pool.map(fetch, urls))    # 并行执行
    # 或用 submit + future
    future = pool.submit(fetch, "url")
    result = future.result()
```

## 3. 多进程（multiprocessing）—— CPU 密集

绕过 GIL，每个进程独立解释器。

```python
from concurrent.futures import ProcessPoolExecutor

def compute(x):
    return sum(i * i for i in range(x))

with ProcessPoolExecutor() as pool:
    results = list(pool.map(compute, [1000000] * 4))
```

**注意**：进程间数据不共享，需序列化传递（开销比线程大），但真正并行。

## 4. 异步（asyncio）—— 高并发 I/O

单线程内用「事件循环 + 协程」实现超高并发，是现代 Python 网络编程的核心。

```python
import asyncio

async def fetch(url):
    await asyncio.sleep(1)   # 模拟异步 I/O（不阻塞事件循环）
    return f"done {url}"

async def main():
    # 并发执行多个协程
    results = await asyncio.gather(
        fetch("a"), fetch("b"), fetch("c")
    )
    print(results)

asyncio.run(main())
```

### 关键概念

```python
async def f(): ...        # 定义协程（coroutine）
await f()                 # 等待协程完成（挂起，不阻塞）
asyncio.create_task(f())  # 创建任务（并发调度）
await asyncio.gather(...) # 并发等待多个
```

**与 C++ 思维的对应**：`async def`/`await` 类似 C++20 的协程（coroutine），都是「单线程内协作式调度」，用于大量 I/O 等待的场景。

## 5. 三模型对比与选择

| 模型 | 适用 | 特点 |
|------|------|------|
| `threading` | I/O 密集 | 简单直观，受 GIL 限制 |
| `multiprocessing` | CPU 密集 | 真正并行，开销大 |
| `asyncio` | 高并发 I/O（网络服务） | 单线程超高并发，代码需 async 化 |

**记忆口诀**：CPU 多用进程，I/O 多用线程，海量网络用 asyncio。

## 6. 线程/进程间通信

```python
# 线程用队列
import queue
q = queue.Queue()
q.put(item)
item = q.get()

# 进程用 multiprocessing.Queue 或 Pipe
from multiprocessing import Queue, Process
```
