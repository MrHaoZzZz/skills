# Python 进阶 · 容器与函数

## 1. 四大容器

### list（列表，可变，有序）

```python
nums = [1, 2, 3]
nums.append(4)          # 尾部加
nums.insert(0, 0)       # 指定位置插入
nums.pop()              # 弹出尾部
nums.remove(2)          # 按值删除
nums[0]                 # 下标访问
nums[-1]                # 倒数第一个
nums[1:3]               # 切片
len(nums)

# 列表推导式（Pythonic 核心）
squares = [x**2 for x in range(10)]              # [0,1,4,...,81]
evens = [x for x in nums if x % 2 == 0]          # 带条件
```

### tuple（元组，不可变）

```python
point = (1, 2)
x, y = point          # 解包
single = (1,)         # 单元素元组要加逗号
```

### dict（字典，键值对）

```python
d = {"a": 1, "b": 2}
d["c"] = 3            # 添加/修改
d.get("x", 0)         # 安全取（不存在返回默认值，不抛异常）
d.keys()              # 所有键
d.values()            # 所有值
d.items()             # 键值对

for k, v in d.items():
    print(k, v)

# 字典推导式
squares = {x: x**2 for x in range(5)}
```

### set（集合，去重，无序）

```python
s = {1, 2, 3}
s.add(4)
s.remove(2)
{1, 2} & {2, 3}       # 交集 {2}
{1, 2} | {2, 3}       # 并集
{1, 2} - {2, 3}       # 差集 {1}
```

**选用原则**：
- 有序可变 → `list`
- 不可变序列 → `tuple`
- 键值查找 → `dict`（O(1)）
- 去重/集合运算 → `set`

## 2. 推导式（comprehension）

Python 标志性特性，简洁优雅。

```python
# 列表、字典、集合、生成器推导式
list_comp  = [x*2 for x in range(5)]
dict_comp  = {x: x*2 for x in range(5)}
set_comp   = {x for x in [1, 2, 2, 3]}
gen_comp   = (x*2 for x in range(5))   # 生成器表达式（惰性）
```

**注意**：推导式要克制，太复杂就改回普通循环（可读性优先）。

## 3. 函数进阶

### 参数类型

```python
def f(a, b, *args, c=1, **kwargs):
    print(a, b)        # 位置参数
    print(args)        # 可变位置参数 → tuple
    print(c)           # 关键字参数
    print(kwargs)      # 可变关键字参数 → dict

f(1, 2, 3, 4, c=5, x=6, y=7)
```

### 参数传递（与 C++ 的区别）

Python 的「引用传递」容易误解：

```python
def modify(lst):
    lst.append(4)        # 修改的是同一对象

def reassign(lst):
    lst = [9, 9, 9]      # 只是让局部变量指向新对象，不影响调用者

a = [1, 2, 3]
modify(a)     # a 变成 [1,2,3,4]
reassign(a)   # a 仍为 [1,2,3,4]，未变
```

**要点**：可变对象（list/dict）在函数内可被修改；但「重新赋值」只影响局部。不可变对象（int/str/tuple）永远是「值」的副本语义。

### lambda（匿名函数）

```python
add = lambda a, b: a + b
add(1, 2)              # 3

# 常用于 sort 的 key
students = [("bob", 20), ("alice", 22)]
students.sort(key=lambda s: s[1])   # 按年龄排序
```

### map/filter/reduce

```python
list(map(lambda x: x*2, [1, 2, 3]))            # [2,4,6]
list(filter(lambda x: x > 1, [1, 2, 3]))       # [2,3]
```

> 但通常列表推导式比 map/filter 更 Pythonic、更可读。

## 4. 迭代与解包

```python
# enumerate：同时取下标和值
for i, x in enumerate(["a", "b", "c"]):
    print(i, x)

# zip：并行遍历
for name, score in zip(names, scores):
    print(name, score)

# 解包
a, b = 1, 2
a, b = b, a        # 交换（无需临时变量）
first, *rest = [1, 2, 3, 4]   # first=1, rest=[2,3,4]
```
