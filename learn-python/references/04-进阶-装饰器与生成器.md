# Python 进阶 · 装饰器、生成器与上下文管理器

这是 Python 最有特色、也最「Pythonic」的三个特性。有 C++/Java 背景的人往往在此停留最久。

## 1. 装饰器（decorator）

装饰器是「**接受函数、返回增强后函数的函数**」，用 `@` 语法糖，在不修改原函数的情况下添加功能（日志、计时、权限、缓存等）。

```python
def timer(func):
    import time, functools
    @functools.wraps(func)        # 保留原函数的元信息（名字、文档）
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.perf_counter() - start:.4f}s")
        return result
    return wrapper

@timer                            # 等价于 slow = timer(slow)
def slow():
    import time
    time.sleep(1)

slow()
```

### 带参数的装饰器

```python
def repeat(times):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            return [func(*args, **kwargs) for _ in range(times)]
        return wrapper
    return decorator

@repeat(3)
def hi():
    return "hi"

hi()   # ['hi', 'hi', 'hi']
```

**理解要点**：装饰器本质是**闭包（closure）+ 高阶函数**。先搞懂闭包（内层函数记住外层变量），装饰器就自然通了。

## 2. 生成器（generator）与迭代器（iterator）

### 迭代器（iterator）

实现 `__iter__` 和 `__next__` 的对象，可被 `for` 遍历，惰性产生值。

```python
it = iter([1, 2, 3])
next(it)   # 1
next(it)   # 2
```

### 生成器（generator）

用 `yield` 的函数，**惰性生成值**，比一次性构造列表省内存。

```python
def count_up_to(n):
    i = 0
    while i < n:
        yield i        # 每次调用 next 才产生一个值
        i += 1

for x in count_up_to(5):
    print(x)           # 0 1 2 3 4

# 生成器表达式
squares = (x**2 for x in range(1000000))   # 惰性，不占内存
```

### 为什么重要（对比 C++ 思维）

```python
# 一次性读入大文件，占内存
lines = open("big.txt").readlines()

# 逐行惰性读取，省内存（推荐）
def read_lines(path):
    with open(path) as f:
        for line in f:
            yield line
```

**价值**：处理大数据流时，生成器把「整批处理」变成「按需取用」，内存占用从 O(n) 降到 O(1)。

## 3. 上下文管理器（with 语句）

`with` 保证资源（文件、锁、连接）**无论是否异常都会正确释放**，是 C++ RAII 的 Python 版。

```python
# 文件：自动关闭
with open("f.txt") as f:
    content = f.read()
# 离开 with 块，f 自动 close，即使异常也保证

# 锁
import threading
lock = threading.Lock()
with lock:
    ...   # 自动 acquire/release
```

### 自定义上下文管理器

```python
from contextlib import contextmanager

@contextmanager
def timer(name):
    import time
    start = time.perf_counter()
    yield                       # yield 之前是 __enter__，之后是 __exit__
    print(f"{name}: {time.perf_counter() - start:.4f}s")

with timer("task"):
    time.sleep(1)
```

## 4. itertools 与 functools（常用工具）

```python
import itertools
itertools.chain([1, 2], [3, 4])       # 拼接
itertools.product("ab", "12")         # 笛卡尔积
itertools.permutations([1, 2, 3])     # 排列
itertools.combinations([1, 2, 3], 2)  # 组合
itertools.islice(gen, 5)              # 惰性取前 n 个

import functools
functools.reduce(lambda a, b: a + b, [1, 2, 3])   # 6（累积）
functools.partial(pow, exp=2)                      # 部分应用
functools.lru_cache()                              # 函数结果缓存
```

**对算法竞赛背景者**：`itertools.permutations/combinations/product` 能大幅简化枚举类代码，`lru_cache` 能让递归 DP 秒变记忆化搜索。
