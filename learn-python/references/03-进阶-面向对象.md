# Python 进阶 · 面向对象

## 1. 类与对象

```python
class Person:
    def __init__(self, name, age):   # 构造方法（不是 __new__）
        self.name = name             # self 类似 Java 的 this
        self.age = age

    def introduce(self):
        return f"{self.name}, {self.age}"

p = Person("Alice", 30)
p.introduce()
```

**与 C++/Java 的差异**：
- 无访问控制修饰符（`private` 是约定，用下划线 `_name` 表示「不要碰」）。
- `self` 必须显式写在方法第一个参数。
- 一切皆对象，方法、类、函数都是对象。

## 2. 鸭子类型（duck typing）

Python 的核心哲学：**「如果它走路像鸭子、叫起来像鸭子，那它就是鸭子」**。不关心对象的类型，只关心它有没有需要的方法/属性。

```python
def make_sound(animal):
    return animal.sound()   # 只要传入的对象有 sound() 方法即可

class Dog:
    def sound(self): return "woof"

class Cat:
    def sound(self): return "meow"

make_sound(Dog())   # "woof"
make_sound(Cat())   # "meow"
# 无需 Dog/Cat 继承同一基类！
```

对比：C++/Java 靠继承/接口实现多态；Python 靠鸭子类型（协议），更灵活。

## 3. 继承与多态

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def sound(self):
        return "?"

class Dog(Animal):
    def sound(self):          # 覆写父类方法
        return "woof"

class Cat(Animal):
    def sound(self):
        return "meow"

for a in [Dog("d"), Cat("c")]:
    print(a.sound())          # 多态：运行时决定
```

### super() 与多重继承

```python
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)     # 调用父类构造
        self.breed = breed
```

Python 支持多重继承，用 **MRO（Method Resolution Order）** 决定方法查找顺序。

## 4. 魔术方法（magic/dunder methods）

以双下划线开头结尾的方法，定义对象的行为。

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):       # 支持 +
        return Vector(self.x + other.x, self.y + other.y)

    def __eq__(self, other):        # 支持 ==
        return self.x == other.x and self.y == other.y

    def __len__(self):              # 支持 len()
        return 2

    def __repr__(self):             # 可读的字符串表示
        return f"Vector({self.x}, {self.y})"

    def __str__(self):              # print 时的表示
        return f"({self.x}, {self.y})"

    def __iter__(self):             # 可迭代
        return iter((self.x, self.y))

v1 = Vector(1, 2) + Vector(3, 4)   # Vector(4, 6)
```

### 常用魔术方法

| 方法 | 作用 |
|------|------|
| `__init__` | 构造 |
| `__str__`/`__repr__` | 字符串表示 |
| `__add__`/`__sub__`/`__mul__` | 算术运算 |
| `__eq__`/`__lt__` | 比较 |
| `__len__` | `len()` |
| `__getitem__`/`__setitem__` | 下标访问 `obj[i]` |
| `__iter__`/`__next__` | 迭代 |
| `__call__` | 让实例可调用 |
| `__enter__`/`__exit__` | 上下文管理器（with）|

## 5. 属性、类变量与静态方法

```python
class Counter:
    count = 0                     # 类变量（所有实例共享）

    def __init__(self):
        Counter.count += 1

    @classmethod                  # 类方法：第一个参数是类
    def get_count(cls):
        return cls.count

    @staticmethod                 # 静态方法：无 self/cls
    def helper():
        return "static"

    @property                     # 属性：像访问字段一样调用方法
    def total(self):
        return self._compute_total()
```

## 6. 数据类（dataclass）

减少样板代码的现代写法（Python 3.7+）。

```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int
    # 自动生成 __init__、__repr__、__eq__

Person("Alice", 30) == Person("Alice", 30)   # True
```

**推荐**：纯数据类优先用 `dataclass`，简洁且少犯错。
