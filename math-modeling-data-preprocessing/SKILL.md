# 数学建模数据预处理

针对竞赛数据集（美赛 A-F 各类题型）的全流程预处理，产出可直接运行的 Python/Matlab 双语言代码。

## 1. 数据评估与必要性判断

先判断该数据集是否需要预处理，明确判断依据：
- 是否存在缺失值、异常值、重复值、数据类型错误、量纲不一致、数据不平衡、时序数据不规整等。
- 若无需处理，说明原因，不执行后续操作。

## 2. 预处理方法与选择（每步写明场景依据）

- **缺失值填充**：均值/中位数/众数填充、线性/多项式插值、KNN 填充。依据示例：时序数据用线性插值、物理参数用均值填充。
- **异常值处理**：Z-score 法 / IQR 法 / 箱线图检测，结合场景逻辑说明保留/修正/删除理由（如违背物理守恒/生态阈值的删除）。
- **标准化/归一化**：说明必要性（如 SVM 需标准化），给出转换公式。
- **编码**：One-Hot / Label Encoding，说明适用场景。
- **复杂数据特征提取**：图像数据（边缘检测）、网络数据（节点-边构建）、空间数据（空间插值）。
- **数据补充**：区分「必须补充」（核心参数/标准常数/行业规范）与「可选补充」（辅助数据），推荐获取途径（Kaggle/UCI、行业报告、EPA/UNEP 等权威机构）；无法获取时按场景逻辑合理假设并标注依据。

## 3. 双语言代码规范

通用要求：
- 代码中醒目标注本地数据路径替换位置（注释、变量名），提供 Windows/Mac/Linux 路径格式示例。
- 加入数据读取失败异常处理，给出报错提示与解决方法。
- 详细注释，标注每步目的、方法、参数含义。
- 输出关键中间结果（缺失值统计、异常值检测结果）。
- 必要时包含可视化模块：预处理前 / 预处理后双可视化绘图。

Python 版本：
- 用 Python 3.8-3.11，基于 Pandas/NumPy/Scikit-learn 等 Anaconda 默认库。
- 代码风格符合 PEP8，注明库安装命令（pip install pandas numpy scikit-learn）。

Matlab 版本：
- 适配 R2020b 及以上，用内置函数（避免第三方工具箱依赖）。
- 避免生僻函数，提供等效替代方案。

## 4. 结果输出

- 处理后数据保存为通用格式（CSV 优先，Matlab 支持 .mat）。
- 展示处理后数据前 10 行 + 后 5 行。
- 说明代码中保存数据到本地的方法和路径设置。
- 提供数据完整性校验方法。
- 撰写可直接放入论文的数据预处理完整结论。

## 5. 预处理过程总结（结构化）

总结需包含：数据原始特征（维度/字段类型/样本量）、核心预处理问题及双语言解决策略对比、本地路径设置常见错误及规避、预处理前后数据对比（缺失值/异常值变化）、论文中描述预处理要点、两种语言方案优缺点与选择建议。
