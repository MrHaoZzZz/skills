# fonts/ —— 思源宋体

`format.cls` 通过 `Path = ./fonts/` 引用以下字体，用前请放到本目录：

- `SourceHanSerifCN-Regular.otf`
- `SourceHanSerifCN-Bold.otf`

下载：Adobe 思源宋体 / Google Noto Serif CJK SC（Source Han Serif CN 与 Noto Serif CJK SC 同源），选 **CN（简体）** 版本。

其余字体（Times New Roman / Arial / Consolas / simkai.ttf）为系统字体，缺失时按上级 [README.md](../README.md) 修改 `format.cls` 或改用精简模板。
