# templates/ —— 模板说明

| 文件 | 用途 |
|------|------|
| `cumcm-template/` | **国赛完整模板(推荐)**。含 `format.cls` + `论文.tex` + `0.摘要` ~ `10.附录` 全套章节模板 + `求解计划.md`。用 XeLaTeX 编译,骨架已按规范拆好子文件。**有字体依赖**,见该目录 `README.md` |
| `论文模板.tex` | **通用精简模板**(`ctexart`,系统字体开箱即用)。国赛/美赛/省赛皆可;国赛若装好字体优先用 `cumcm-template/` |
| `论文模板.pdf` | 精简模板编译预览(108KB),没装 TeX 也能看效果;不是交付物 |
| `建模笔记模板.md` | 每道题的建模笔记模板。建模时随手记,是 AI 写论文的第一手素材 |
| `目录结构模板.md` | 参赛文件夹目录结构模板。复制即用,一次参赛一个文件夹 |

## 使用方式

1. **参赛准备**:按 `目录结构模板.md` 建好参赛文件夹,题目、每题建模笔记、代码、结果分文件夹放好。
2. **每题建模**:用 `建模笔记模板.md` 写 `问题X/建模笔记.md`。
3. **写论文**:国赛优先用 `cumcm-template/`(复制整个目录到 `论文/`,填 `【】` 占位),否则用 `论文模板.tex` 为骨架;同时遵循 [../references/论文写作规范.md](../references/论文写作规范.md)(写什么)与 [../references/论文排版规范.md](../references/论文排版规范.md)(怎么排)。XeLaTeX 编译两次产出 PDF。论文只以 LaTeX 形式交付。
