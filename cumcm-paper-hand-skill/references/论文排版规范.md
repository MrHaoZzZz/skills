## 〇、全局铁律(违反即返工)

1. **中文命名铁律**：所有输出文件（图片、CSV、Python 脚本）文件名**必须中文**，禁止英文。
   - ✅ `温度分布热力图.png` / `预处理数据.csv` / `问题一求解.py`
   - ❌ `temperature_heatmap.png` / `processed_data.csv` / `problem1_solve.py`
2. **正文一律自然段落**：禁止分点符号（`1.` `2.` 或 `●` `○`）。
3. **禁止正文加粗**：`\textbf` 仅用于——摘要中的"对于问题X"、问题重述中的"问题N："、以及建模步骤标题"步骤N："。
4. **图宽 `0.8\textwidth`，表宽 `\textwidth`**。
5. **所有图表必须被正文引用**（"如图X所示""如表X所示"），图表标题/caption/坐标轴全中文。
6. **全文任何位置不加 `\newpage`**（章、节、子节之间自然接续），禁止人为断页。
7. **图文件不写 `set_title()`**，标题由 `\caption{}` 承担；图内只允许：数据、坐标轴标签刻度、图例。
8. **表格格子文字一行显示**，不换行。
9. tex 中只写可编译的 LaTeX，**不可出现 `...（提示语）` 等模板指令**（写完必须清理占位注释）。

## 一、摘要

**字数硬约束**：

| 段落 | 字数 | 说明 |
|------|------|------|
| 开头段 | ≤30 字 | 固定 |
| 结尾段 | ≤20 字 | 固定 |
| **总计** | **≤900 字** | 不可超过 |
| 页数 | 必须 = 1 页 | 编译后验证 |

**各问题字数按类型弹性分配**（扣除头尾后约 850 字）：

| 问题类型 | 占比 | 说明 |
|----------|------|------|
| 建模求解型（优化/预测/分类/评价） | 高 ≈30–35% | 方法+求解+结果占篇幅 |
| 数据分析型（统计/探索/可视化） | 中 ≈20–25% | 处理+发现+结论 |
| 建议总结型（建议/总结/改进） | 低 ≈10–15% | 一笔带过 |

**框架**（每问选类型替换 `【】`）：

```latex
\begin{abstract}
本文针对【题目背景】问题，提出了基于【主要方法】的系统解决方案。

% 每问从这里选对应类型复制
\textbf{针对问题X：}……

综上，本文为【领域】问题提供了高效解决方案。

\keywords{【关键词1】；【关键词2】；【关键词3】；【关键词4】；【关键词5】；【关键词6】}
\label{abstract:end}
\end{abstract}
```

**三种类型**：

- **① 有数据**（含预处理→建模→求解全流程）：`本问是【类型】问题，需【要求】。首先，对附件数据预处理，提取【特征】，【清洗/标准化】。接着，【变量筛选/降维/参数选择】。然后，采取【模型】进行【求解】。最后，【对比/验证/排序】，给出【输出】。结果显示，\textbf{【数值结果】}，模型有效地【评价】。`
- **② 无数据**（机理/方程/优化模型）：`首先，分析【机理/物理过程/目标约束】，建立【方程/动力学/优化模型】。接着，设定【参数/初始条件】。然后，通过【数值方法/仿真/求解算法】求解，得到【结果】。结果显示，\textbf{【数值结果】}……`
- **③ 建议型**：`本问是建议总结问题，需【要求】。基于前文分析，从【角度1】和【角度2】出发，给出【N】条建议。核心结论为\textbf{【要点】}。`

**一页验证（编译后必做）**：

```bash
PAGE=$(grep 'abstract:end' 论文/论文.aux | grep -oE '\{[0-9]+\}' | head -1 | tr -d '{}')
if [ "$PAGE" -gt 1 ]; then echo "摘要超出一页（第${PAGE}页），需缩减"; fi
```

`PAGE>1` 则按比例缩减各问字数重编译，直到 `PAGE=1`。**禁止**摘要写公式、写模型检验、超字数、末尾加 `\newpage`。

## 二、统一表格规范(longtable)

**全论文所有表格**（符号说明、算法对比、预处理对比、模型结果、检验分析等）**必须统一用 `longtable` + `>{\centering\arraybackslash}p{}`**，不得用 `tabular`/`tabularx`。

```latex
\begin{longtable}{>{\centering\arraybackslash}p{0.18\textwidth}>{\centering\arraybackslash}p{0.78\textwidth}}
  \caption{表名（中文）}
  \label{tab:标签} \\
  \toprule
  列1 & 列2 \\
  \midrule
  \endfirsthead
  \caption{表名（续）} \\
  \toprule
  列1 & 列2 \\
  \midrule
  \endhead
  \bottomrule
  \endfoot
  内容 & ... \\
  ... & ...
\end{longtable}
```

**铁律**：`\caption{...}` 单独一行，`\label{...} \\` 紧跟其后，`\\` 只写在 `\label` 行末；数据行末也必须有 `\\`；所有列居中：`>{\centering\arraybackslash}` 不可省（否则 `Misplaced \noalign`）。

**列宽公式（强制）**：`\tabcolsep` 每列左右各 6pt，总计 `1.04 − 0.04×N`（N 为列数），**不可等于 1.0**：

| 列数 | 比例总和 | 示例分配 |
|------|----------|----------|
| 2 | **0.96** | `{0.18+0.78}` |
| 3 | **0.92** | `{0.16+0.16+0.60}` |
| 4 | **0.88** | `{0.12+0.12+0.12+0.52}` |
| 5 | **0.84** | `{0.12+0.18+0.18+0.18+0.18}` |
| 6 | **0.80** | `{0.10+0.14+0.14+0.14+0.14+0.14}` |
| 7 | **0.76** | `{0.10+0.11×6}` |
| 8 | **0.72** | `{0.09×8}` |
| 9 | **0.68** | `{0.08+0.075×8}` |
| 10 | **0.64** | `{0.064×10}` |

左侧标签列取窄值，各列可据实际最长内容微调，**总和必须等于该列数对应强制值**。编译后 `grep 'Overfull.*hbox'` 复查。

## 三、9 框分析流程图(固定模板)

每个 `5.X.1.分析与准备.tex` 中的"具体分析"末尾放一张流程图。**严格逐字复制，只替换 `{}` 中文字，其余一字不改，每框 ≤7 字**：

```latex
\begin{figure}[ht]
  \begin{center}
    \begin{tikzpicture}[x=1cm, y=0.7cm]
      \node[box] (n11) at (0, 0) {...};
      \node[box] (n12) at (5, 0) {...};
      \node[box] (n13) at (10, 0) {...};
      \node[box] (n22) at (5, -3) {...};
      \node[box] (n21) at (0, -3) {...};
      \node[box] (n23) at (10, -3) {...};
      \node[box] (n31) at (0, -6) {...};
      \node[box] (n32) at (5, -6) {...};
      \node[box] (n33) at (10, -6) {...};
      \draw[arrow] (n11) -- (n12);
      \draw[arrow] (n12) -- (n13);
      \draw[arrow] (n23) -- (n22);
      \draw[arrow] (n22) -- (n21);
      \draw[arrow] (n13) -- ++(0,-1.0) -| (n23);
      \draw[arrow] (n21) -- (n31);
```

## 四、各章节规范

### 1. 引言
- 问题背景（2–3 段，不分点）：宏观背景→问题来源/原因→当前困境→解决渴求。
- 研究意义（可选，1 段）：社会意义 + 科研意义。
- 问题重述：`\textbf{问题N：}` 每问 ≤2 行，问题本质缩写，删背景，不加分点符号。

### 2. 总体分析
三段式，纯文字，**不画流程图**：
- 第1段：一句话总体表达；第2段：逐问串联"针对问题X建立了XX来解决XX"；第3段：总结各问题递进关系。

### 3. 模型假设
- 两段式：第1段"为简化问题，本文做出以下假设："；随后 `itemize`，每条 `\textbf{假设N：}`，≤2 行，数量 = 问题数。

### 4. 符号说明
- 用第二节的 `longtable` 模板（2 列 `{0.18+0.78}`）。

### 5. 模型的建立与求解
主文件按 N 动态生成（N>4 新增、N<4 删除）：

```latex
\section{模型的建立与求解}
\input{5.1.问题1的建立求解.tex}
% 复制改名 5.2 ~ 5.N，在此逐个 \input
```

每个 `5.X.问题X的建立求解.tex` 拆为 2 个子文件（从 `5.1.1`/`5.1.2` 模板复制改名）：

```latex
\subsection{问题X的模型的建立和求解}
\input{5.X.1.分析与准备.tex}
\input{5.X.2.建模与求解.tex}
```

**拆分原则**：模型建立与模型求解必须在一起（求解大量引用建立的公式/变量/参数，拆开反而符号不一致）。总结建议类问题不分小节，自然段落。

#### 5.X.1 分析与准备
- **具体分析**（三段式 + 9 框流程图）：第1段针对问题X+类型+大致方法；第2段"首先…接着…然后…最后…"串联，不换段；第3段引出流程图。**不讲检验、不讲结果**。
- **模型准备**：引文→分析→表格→结论。含**数据预处理**（仅问题1）和**算法选择**（问题1必写，其他视情况）。
  - 数据预处理 5 段：预处理原因 / 数据理解与提取 / 预处理步骤（清洗→标准化公式→特征衍生）/ 预处理结果（前后统计量对比）/ 总结。
  - 算法选择 4 部分：问题本质定性 → 候选算法+评估维度 → `longtable` 对比表（含具体算法中文名+英文缩写与优/良/中/差等级，禁止"算法A"）→ 分析对比结果+总结引出。

#### 5.X.2 建模与求解
- **模型建立**（占篇幅最大，三段式）：
  - 第1段开篇引文点明"针对问题X，从XX角度建立XX模型，具体过程如下"。
  - 第2段按编号步骤 `\textbf{步骤N：标题}` 展开，**每步至少 6–7 个公式**，逐步推导不跳步，公式间用"将式(X)代入式(Y)可得""由XX性质可知"串联，每个公式后紧跟变量说明段 `其中，$X$表示...，$Y$表示...。`。
  - 各类型步骤划分：
    - **优化类**：1 目标函数建立 → 2 约束条件建立（逐约束编号）→ 3 核心机理建模 → 4 求解算法建模（流程公式+参数表）。必须含目标函数+决策变量+约束条件三要素。
    - **评价类**：1 指标体系构建（指标表+无量纲化公式）→ 2 权重确定（熵权法/AHP 完整推导+中间结果表）→ 3 综合评价（TOPSIS/模糊综合，至少 5–6 公式）。
    - **分类/预测类**：1 特征工程 → 2 模型选定与构建（含损失函数/优化目标/正则项）→ 3 训练与评估（指标公式+训练策略）。
    - **机理分析**：1 机理分析框架 → 2 关键变量关系建模 → 3 模型整合与参数辨识。
  - 第3段总结桥接："综上所述，本节完成了XX模型建立，接下来将基于此求解。"
- **模型求解**：引文→表/图→分析。数据结果用表格突出，趋势/对比用图展示。

### 6. 模型检验与分析
- 结构：开头引文→二级标题分类→文字解释→表/图→分析。
- 子节：**误差分析**（优先 5 折交叉验证）+ **灵敏度分析**（改输入/参数看输出）；结果优先用表格。
- 如模板结构不适配当前题目，自行组织，但须满足"文字引入 + 表格结果 + 文字分析"。

### 7. 模型评价
- 优点 4 条 + 缺点 2 条，**按模型写不按问题写**，优点多于缺点，`itemize`，每条 ≤3 行。

### 8. 模型改进与推广
- 各一段自然段落，不分点。

### 9. 参考文献
- **必须按论文实际内容生成，禁止保留模板示例文献**。
- 标签 `作者姓氏+年份+关键词`（如 `behzadian2012topsis`）；国标 GB/T 7714-2015，纯文本一行，**严禁** `\emph/\textbf/\textit/\underline`，删 DOI。
- 数量 8–15 条；每条必须被正文 `\cite{}` 引用，无引用条删除。
- 引用位置：模型建立（方法原始文献）、模型求解（算法文献）、模型检验（对比方法文献）、引言（领域背景文献）。
- 写完对照正文 `\cite{}` 逐一核对一一对应。

### 10. 附录
- 附件说明表，两列 `{LX}`，`\renewcommand{\arraystretch}{1.2}`；不写运行环境/硬件环境。
- 所有源码/大表格/冗长推导放附录，正文只留伪代码或流程图。

## 五、编译与排版优化(收尾必做)

```bash
cd 论文
xelatex -interaction=nonstopmode 论文.tex
xelatex -interaction=nonstopmode 论文.tex
grep -c 'Error' 论文.log        # 必须为 0
grep 'Overfull\|Underfull\|Float too large' 论文.log
```

1. `Error` 必须为 0，有错则修复重编译直到 0。
2. 0 错误后自动做**排版优化**：定位 `Overfull/Underfull/Float too large` 对应 tex 行 → 修复（缩短表格文字、调整图表尺寸、收紧段落）→ `xelatex ×2` 重编译 → 复查。
3. 直到日志干净、排版紧密、无溢出无大面积空白、图表正常。

## 六、求解计划.md 结构

`求解/求解计划.md` 固定六部分（模板见 [templates/cumcm-template/求解计划.md](../templates/cumcm-template/求解计划.md)）：

1. **题目总体方向**（一整段）：问题类型、核心任务、数据规模、研究递进逻辑。
2. **各题求解思路**（每问）：具体分析（输入/输出/难点/定位）+ 建模（核心公式+方法选择理由）+ 主/备选方法对比表。
3. **各题输出标准**：每问必须产出的图表、表格、数值结果清单。
4. **操作步骤**：每问从加载→预处理→建模→求解→输出的完整链路，标注数据在问题间流转。
5. **文件清单**：代码/图/CSV 文件名（中文）。
6. **异常预案**：数据缺失、模型不收敛等备选处理。
