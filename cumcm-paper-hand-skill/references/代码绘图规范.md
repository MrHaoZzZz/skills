> 📌 从 [Mrite](https://github.com/i3by4t3oyt/Mrite) 数模智能体的生产求解规范提取，供求解阶段（生成代码、出图、出结果 CSV）使用。**中文文件名**与**先算后画**是硬性要求。

## 一、Python 脚本公共头部

每个脚本开头必须有（**解决 Windows 控制台中文乱码，缺了输出全乱码**）：

```python
import sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

import pandas as pd
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import os, warnings
warnings.filterwarnings('ignore')

# 中文字体（跨平台，见第二节）
plt.rcParams['font.sans-serif'] = ['STHeiti', 'SimHei', 'Heiti TC',
    'Arial Unicode MS', 'Hiragino Sans GB', 'PingFang SC',
    'Microsoft YaHei', 'Songti SC', 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False
plt.rcParams['figure.dpi'] = 150
plt.rcParams['savefig.dpi'] = 150
plt.rcParams['savefig.bbox'] = 'tight'

def despine(ax):
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)

BASE_DIR = os.path.dirname(os.path.abspath(__file__))
FIG_DIR = os.path.join(BASE_DIR, '图片')
OUT_DIR = os.path.join(BASE_DIR, '结果')
os.makedirs(FIG_DIR, exist_ok=True)
os.makedirs(OUT_DIR, exist_ok=True)

def save_fig(fig, name_cn):
    """保存图片，name_cn 必须中文，如 '温度分布热力图.png'"""
    fig.savefig(FIG_DIR + '/' + name_cn)
    plt.close(fig)

def save_csv(df, name_cn):
    """保存CSV，name_cn 必须中文，如 '回归分析结果.csv'"""
    df.to_csv(OUT_DIR + '/' + name_cn, index=False, encoding='utf-8-sig')
```

## 二、中文字体(跨平台)

用上面 `font.sans-serif` 列表即可覆盖 macOS / Windows / Linux。若出现 `Glyph missing from font` 等中文渲染警告，修正字体配置后重跑。

## 三、库与框架约束

- **绘图只允许 matplotlib**，严禁 seaborn 及任何其他可视化库：

  | 禁止 | 替代 |
  |------|------|
  | `sns.set_style()` | `plt.rcParams` + `ax.grid(alpha=0.3, linestyle='--')` |
  | `sns.color_palette()` | `plt.cm.viridis(np.linspace(0.1, 0.9, n))` |
  | `sns.heatmap()` | `ax.imshow()` + `plt.colorbar()` |
  | `sns.despine()` | `ax.spines['top'/'right'].set_visible(False)` |

- 必要依赖：`pandas, numpy, matplotlib, scipy, scikit-learn, chardet`。
- 按需：`xgboost, PyPDF2, python-docx`。
- **机器学习框架只允许 PyTorch**，禁止 TensorFlow / Keras / JAX。

## 四、两阶段执行(先算后画)

每个求解脚本必须按此顺序：

```
第一阶段：纯计算
  数据加载 → 预处理 → 建模 → 求解 → 得到所有数值结果
第二阶段：检查 + 绘图
  → 打印每组数据的 min/max/mean/std/CV/amplitude（供论文引用）
  → 每种分析结果都画图
```

**必须打印统计量**：每组数值结果的 `min/max/mean/std/CV/amplitude`，论文正文引用这些数字。

## 五、文件组织与命名

- 每题一个 `.py`，**中文命名**，放 `求解/问题<序号>/`，如 `问题一求解.py`。
- 图片存 `求解/问题X/图片/`，结果 CSV 存 `求解/问题X/结果/`。
- 论文通过相对路径引用图片：`../求解/问题X/图片/xxx.png`。
- 表格/图/CSV/脚本文件名一律中文（见全局铁律）。

---

## 六、绘图原则

- 每题至少 **4–6 张图**，覆盖主要分析维度，多多益善。

  | 图表类型 | 适用场景 |
  |----------|----------|
  | 柱状图 | 类别对比、分组对比 |
  | 折线图 | 趋势变化、时间序列 |
  | 热力图 | 矩阵数据、相关性 |
  | 散点图 | 两变量关系、分布 |
  | 饼图 | 占比构成 |
  | 箱线图 | 多组分布对比 |

- **图上不画 `set_title()`**，标题由论文 `\caption{}` 承担；图内只允许：数据、坐标轴标签刻度、图例（全中文）。

### 美观规则

- 配色用内置 colormap（`viridis`、`RdBu_r`、`tab10`、`Set3`）。
- 折线图：线宽 ≥1.5pt，带标记点。
- 柱状图：柔和色 + 白边 `edgecolor='white', linewidth=0.5`。
- 散点图：`alpha=0.7, edgecolors='black', linewidth=0.5`。
- 网格：`ax.grid(alpha=0.3, linestyle='--')`；去上右边框 `despine(ax)`。

## 七、提速与防绕圈

1. **不绕圈**：同一操作最多重试 3 次，失败换方案重写。
2. **先读后写**：写代码前先读数据摘要确认列名/类型，不要写完再报错修。
3. **复用结果**：已有 CSV/图片直接用，不要重跑。
4. **不做多余的事**：不探索目录结构、不测试 Python 环境、不写测试文件。
5. 脚本报错修复后重跑，通过后再做下一问；有问题**一次写对**优于反复调试。
