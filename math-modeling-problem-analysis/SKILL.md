# 数学建模赛题分析与模型选择

用于对数学建模赛题（国赛 CUMCM / 美赛 MCM-ICM）做结构化分析、题型归类与模型选型。

## 一、前置信息说明（让 AI 了解用户）

收集参赛者信息后再作答：
- 团队情况：零编程基础 / 有基础建模经验 / 首次参赛 / 多次参赛。
- 擅长语言与库：Python（SciPy/Pandas/NetworkX/PuLP）、Matlab（ODE 求解器/整数规划工具箱）、R（ggplot2/caret）。
- 需求重点（标注优先级）：模型创新性 / 代码可执行性 / 数据处理与图表生成 / 论文写作素材 / 模型检验与鲁棒性分析。
- 获奖目标：O/F 奖（特等奖）、M 奖（一等奖）、H 奖（二等奖）等。

## 二、题目分析（通用逻辑）

- 逐句解析题目，区分「背景信息 / 核心问题 / 已知条件（数据/参数/规则）/ 约束条件（物理规律/场景规则/资源限制）」，用表格分列。
- 小问划分：列出各小问「直接目标」「隐含目标」（表面求数值，实为后续建模铺垫）「输出要求」，说明各小问关联性（基础模型→场景拓展→多目标优化）。
- 逻辑关系：用思维导图展示参数/变量/目标之间的依赖关系与传递路径。
- 题型定位：判断每问属于「机理分析 / 预测建模 / 优化决策 / 统计分析 / 网络构建」，注明是否需要「机理/逻辑定框架 + 数据提精度」。

## 三、题型与赛题对照表

美赛题号与典型题型：

| 题号 | 题型 | 典型算法 |
|------|------|----------|
| A 题 | 物理机理 / 连续型 | ODE+PDE、参数校准、菲涅尔/扩散方程 |
| B 题 | 离散决策 / 优化 | 整数规划、动态规划、贪心+约束 |
| C 题 | 大数据统计 | 回归、随机森林、Hurdle/Tobit、聚类 |
| D 题 | 运筹网络优化 | 最短路径、最大流、网络流、图论 |
| E 题 | 环境科学 | 高斯扩散、生态模型、可持续性评估 |
| F 题 | 政策与社会 | 系统动力学、博弈论、指标体系 |

## 四、模型选择：基础 + 创新双方案

针对每个小问推荐 2 种模型方案，紧扣题目核心逻辑，禁止脱离场景的纯理论模型：

**方案 1（基础保分）**：经典模型 + 竞赛适配改进点。确保可解释、无逻辑漏洞、难度适中。例：
- 物理机理类：ODE + 参数校准
- 决策优化类：整数规划 + 约束优先级调整
- 统计分析类：线性回归 + 特征筛选
- 网络类：最短路径 + 动态权重修正
- 环境类：高斯扩散 + 场景修正

**方案 2（创新冲奖）**：三类创新方向任选其一——
1. 算法改进创新（改进 BP 神经网络、改进 SVM）
2. 交叉领域创新（SIR 模型模拟舆论传播、热传导模型用于技术扩散）
3. 算法组合创新（灰色-BP 混合模型）

每个模型需说明：核心原理（1 段通俗语言）、适配性（为何适合本题）、创新点（与传统方法差异）、局限性与规避方案、可视化流程（场景抽象→变量定义→模型构建→数据适配→求解迭代→结果验证）。

最后输出表格：问题 X / 问题描述 / 主要解题思路 / 方案一模型及原因 / 方案二推荐模型及原因。

## 五、赛题全维度分析（用于多题选题）

对全套题目做横向对比时输出：
- 专业翻译（数学建模语境精准翻译，不意译偏差）。
- 每题整体类型 + 每小问独立类型。
- 每小问推荐算法及理由（结合算法特性、题型、评分偏好）。
- 难度系数（1-5 分）+ 评分依据（模型复杂度、数据获取难度、创新设计要求、建模工作量、综合分析要求），按难度从易到难排序。
- 每题 3-5 个核心解题难点、2-4 个核心要点、分步骤解题思路、O/F 奖获奖要点。
- 精准选题建议：按专业背景（数学/统计、计算机/AI、工科/理科、经管/文科、跨专业）和建模基础（零基础/中等/高阶）给「推荐 / 谨慎选择 / 不推荐」三级建议及原因。
