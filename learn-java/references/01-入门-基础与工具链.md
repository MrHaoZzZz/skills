# Java 入门 · 基础与工具链

## 1. 什么是 Java

Java 是一门「编译 + 解释」混合的静态类型语言，口号是 **"Write Once, Run Anywhere"（一次编写，到处运行）**。

核心机制：源码编译成**字节码（bytecode）**，由 **JVM（Java Virtual Machine）** 在任何平台解释/编译执行。这带来跨平台能力，但需要 JVM 这个「中间层」。

类比：JVM 像「翻译官」，把统一的字节码翻译成不同操作系统能懂的指令。

### 这门语言能做什么？从黑框到图形界面

你之前一直在「黑框」（terminal）里跑程序，可能会疑惑：这怎么变成窗口、App 和网页？

**关键认知**：所有程序本质都是「输入 → 处理 → 输出」。黑框程序 = 输入键盘 + 输出字符；图形程序 = 输入鼠标/触摸事件 + 输出「调用图形库画界面」。**变的只是输出这一环，处理逻辑完全不变。**

Java 在现实世界的主战场：
- **企业后端**：银行/电商/大厂的服务器系统（Web 后端，绝对主力）
- **Android 应用**：移动端图形界面
- **桌面 GUI**：JavaFX（现代）、Swing（老）
- 大数据：Hadoop/Spark

Java 写图形界面可用 **Swing**（JDK 自带，无需额外安装，适合尝鲜）：

```java
import javax.swing.*;
public class HelloGUI {
    public static void main(String[] args) {
        JFrame frame = new JFrame("Hello");
        frame.add(new JLabel("Hello, GUI!"));
        frame.setSize(300, 200);
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setVisible(true);   // 显示窗口
    }
}
```

```bash
javac HelloGUI.java && java HelloGUI
```

### 界面与逻辑分离（工程核心思想）

图形界面真正的关键不是「画图」，而是**把界面（壳）和逻辑（核心）分开**：

- **逻辑**：游戏规则、数据、计算——就是你在黑框里也能跑的那部分（如棋盘类、走子判断）。
- **壳**：Swing/JavaFX 窗口、鼠标事件、画棋盘——只负责「接收输入 + 显示结果」。

壳通过逻辑暴露的几个公开方法（**接口/契约**）来调用它。所以同一个逻辑可以接 Swing 壳、黑框文字壳、Web 壳，**逻辑一行不改**。

如果你做过「GUI 框架是别人给、自己只填底层逻辑」的课程项目（比如黑白棋），回顾一下：GUI 的 `mouseClick` 调用你的 `playAt()`，`redraw()` 调用你的 `pieceAt()` 读状态再画出来——这就是「壳调用逻辑」。建议给那个逻辑补一个**黑框文字版壳**（`System.out` 打印棋盘 + 读坐标 + 调 `playAt`），你会彻底理解「界面只是壳，逻辑才是核心」。

> **建议路径**：先用黑框掌握语言本身（OOP、集合、并发）→ 再学图形化（JavaFX 或 Android）。其实 Java 最主流的「界面」是 **Web 后端 + 前端网页**，图形化只是其中一条支线。

## 2. 关键概念：JDK / JRE / JVM

| 缩写 | 全称 | 作用 |
|------|------|------|
| **JVM** | Java Virtual Machine | 运行字节码的虚拟机 |
| **JRE** | Java Runtime Environment | 运行环境（含 JVM + 核心类库）|
| **JDK** | Java Development Kit | 开发工具包（含 JRE + 编译器 javac 等）|

**开发需要 JDK，运行只需要 JRE**（新版 JDK 常自带运行时）。

## 3. 第一个程序

Java 是**强面向对象**语言，一切代码都在「类（class）」里。

```java
// 文件名必须是 Hello.java（与 public 类同名）
public class Hello {
    public static void main(String[] args) {   // 程序入口，固定签名
        System.out.println("Hello, Java");     // 输出并换行
    }
}
```

编译运行：

```bash
javac Hello.java      # 编译成 Hello.class（字节码）
java Hello            # 运行（不带 .class 后缀）
```

**术语**：`public`（公开）、`static`（静态）、`void`（无返回）、`main` 是固定入口方法。

## 4. 基础类型与变量

Java 是静态类型，基础类型（primitive types）有 8 种：

| 类型 | 大小 | 默认值 | 说明 |
|------|------|--------|------|
| `byte` | 1 字节 | 0 | -128~127 |
| `short` | 2 字节 | 0 | |
| `int` | 4 字节 | 0 | 最常用整数 |
| `long` | 8 字节 | 0L | 后缀 L |
| `float` | 4 字节 | 0.0f | 后缀 f |
| `double` | 8 字节 | 0.0d | 最常用浮点 |
| `char` | 2 字节 | '\u0000' | Unicode 字符 |
| `boolean` | 1 位 | false | true/false |

```java
int age = 30;
double score = 9.5;
boolean ok = true;
char letter = 'A';
String name = "Alice";   // String 是「引用类型」（对象），不是基础类型

// 现代 Java 支持 var 局部变量类型推断（Java 10+）
var count = 10;          // 推断为 int
```

**易错点**：
- `int` 除法：`5 / 2 == 2`（整数除法截断），要浮点结果用 `5.0 / 2`。
- `String` 比较**不能用 `==`**（比较的是引用），要用 `equals()`。

## 5. 控制流

```java
// 条件
if (age >= 18) {
    System.out.println("adult");
} else if (age >= 13) {
    System.out.println("teen");
} else {
    System.out.println("child");
}

switch (day) {                 // 支持 int/String/enum
    case 1: System.out.println("Mon"); break;
    case 2: System.out.println("Tue"); break;
    default: System.out.println("other");
}

// 现代 switch 表达式（Java 14+）
String result = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    default -> "other";
};

// 循环
for (int i = 0; i < 10; i++) { ... }
for (int x : arr) { ... }               // 增强 for（foreach）
while (cond) { ... }
do { ... } while (cond);
```

## 6. 方法（函数）

```java
public static int add(int a, int b) {
    return a + b;
}
```

**关键点**：Java **只有按值传递（pass-by-value）**。对基础类型传值副本；对对象，传的是「引用地址」的副本——所以方法内能修改对象内容，但不能让调用者的引用指向新对象。

```java
static void change(int x) { x = 100; }          // 不影响调用者（值拷贝）
static void change(StringBuilder sb) { sb.append("!"); }  // 能改内容（引用副本指向同一对象）
```

## 7. 数组与 String

```java
int[] arr = new int[5];          // 定长数组
int[] nums = {1, 2, 3, 4, 5};    // 初始化
System.out.println(nums.length);  // 长度（属性，不是方法）
int first = nums[0];

// 多维数组
int[][] grid = new int[3][4];

// String 常用操作
String s = "hello";
s = s.toUpperCase();              // "HELLO"（String 不可变，返回新对象）
int len = s.length();
boolean eq = s.equals("HELLO");
String sub = s.substring(0, 2);   // "HE"
String joined = String.join(", ", "a", "b");  // "a, b"

// 可变字符串用 StringBuilder（频繁拼接时性能更好）
StringBuilder sb = new StringBuilder();
sb.append("a").append("b");
```

**重要概念**：`String` **不可变（immutable）**——每次「修改」其实创建新对象。频繁拼接用 `StringBuilder`。
