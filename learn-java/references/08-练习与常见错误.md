# Java 巩固 · 常见错误与综合练习

## 1. 高频易错点 Top 10

### 1. 用 `==` 比较字符串

```java
String a = "hello";
String b = new String("hello");
a == b;        // false！比较的是引用
a.equals(b);   // true（比较内容）
```

### 2. 整数除法

```java
5 / 2        // 2，不是 2.5
5.0 / 2      // 2.5
```

### 3. 空指针异常（NullPointerException）

```java
String s = null;
s.length();   // 崩溃！
// 对策：判空、Optional、Objects.requireNonNull
```

### 4. 数组越界

```java
int[] a = new int[3];
a[3] = 1;    // ArrayIndexOutOfBoundsException
```

### 5. 集合遍历时修改

```java
for (String s : list) {
    if (bad(s)) list.remove(s);   // ConcurrentModificationException！
}
// 正确：用迭代器 it.remove()，或用新集合收集
```

### 6. 泛型类型擦除导致的坑

```java
List<String> l1 = new ArrayList<>();
List<Integer> l2 = new ArrayList<>();
l1.getClass() == l2.getClass();   // true，运行时都是 ArrayList
```

### 7. 重写 equals 未重写 hashCode

```java
// 会导致 HashMap/HashSet 行为错误
```

### 8. 资源未关闭

```java
// 不用 try-with-resources，忘 close 导致资源泄漏
```

### 9. 静态方法访问非静态成员

```java
public class A {
    int x;
    static void m() { x = 1; }   // 编译错！静态方法不能访问实例变量
}
```

### 10. switch 忘记 break（旧语法）

```java
switch (x) {
    case 1: doA();   // 忘 break，会「贯穿」到 case 2
    case 2: doB();
}
```

## 2. 综合练习（由易到难）

### 练习 A：字符串处理
反转字符串、判断回文、统计字符频率（用 HashMap）。

### 练习 B：集合应用
用 `HashMap` 实现一个「单词频率统计器」，并输出频率 Top N。

### 练习 C：面向对象设计
设计一个简单的「银行账户」系统：`Account` 类 + 转账方法（含并发安全），用接口定义能力。

### 练习 D：Stream 数据管道
从 `List<Person>` 中筛出成年人、按年龄排序、取名字组成字符串。

### 练习 E：并发编程
用线程池 + `ConcurrentHashMap` 实现一个多线程计数器，验证结果正确。

### 练习 F：小项目
命令行「待办事项 Todo List」：增删改查、持久化到文件、单元测试、Maven 构建。
