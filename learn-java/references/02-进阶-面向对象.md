# Java 进阶 · 面向对象

Java 是纯面向对象语言，这一章是 Java 的「心脏」。

## 1. 类与对象

```java
public class Person {
    // 成员变量（字段），通常 private
    private String name;
    private int age;

    // 构造方法（与类同名，无返回类型）
    public Person(String name, int age) {
        this.name = name;   // this 指当前对象
        this.age = age;
    }

    // 重载构造方法
    public Person(String name) {
        this(name, 0);      // 调用另一个构造方法
    }

    // getter / setter
    public String getName() { return name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }
}

// 使用
Person p = new Person("Alice", 30);   // new 创建对象
System.out.println(p.getName());
```

**关键点**：
- `this`：当前对象引用。
- **封装**：字段 private，通过 getter/setter 访问。
- Java 的「对象」存在堆上，`p` 是引用（reference），指向堆中的对象。

## 2. 封装、继承、多态

### 继承（Inheritance）

```java
public class Animal {
    protected String name;      // protected：子类可访问
    public void eat() { System.out.println("eating"); }
}

public class Dog extends Animal {   // Java 单继承，只能 extends 一个类
    public void bark() { System.out.println("woof"); }
}
```

### 方法重写（override）

```java
public class Animal {
    public void sound() { System.out.println("?"); }
}

public class Dog extends Animal {
    @Override                        // 注解：标记重写，编译器检查
    public void sound() { System.out.println("woof"); }
}
```

### 多态（Polymorphism）

```java
Animal a = new Dog();      // 父类引用指向子类对象
a.sound();                 // 输出 "woof"（运行时绑定到 Dog 的实现）
```

**关键点**：Java 方法默认就是「虚方法」，运行时动态绑定（与 C++ 不同，无需 `virtual`）。多态是设计模式的基础。

## 3. 抽象类与接口

### 抽象类（abstract class）

不能实例化，可有抽象方法（无方法体）和具体方法。

```java
public abstract class Shape {
    public abstract double area();      // 抽象方法，子类必须实现
    public void describe() { System.out.println("a shape"); }
}
```

### 接口（interface）

定义「能做什么」的契约。Java 8+ 接口可有 default 方法和 static 方法。

```java
public interface Drawable {
    void draw();                        // 抽象方法（public abstract）
    default void print() {              // default 方法：有默认实现
        System.out.println("printing");
    }
}

public class Circle implements Drawable {
    @Override
    public void draw() { System.out.println("drawing circle"); }
}
```

### 接口 vs 抽象类

| 特性 | 抽象类 | 接口 |
|------|--------|------|
| 继承数量 | 单继承 | 可实现多个接口 |
| 含义 | is-a（是什么） | can-do（能做什么） |
| 字段 | 可有状态 | 只能常量（static final） |
| 构造器 | 有 | 无 |

**惯用法**：优先用接口定义能力，抽象类用于「部分实现共享」。

## 5. 关键关键字

```java
final int MAX = 100;            // 常量，不可改
final class Immutable {}        // 不可被继承
final void m() {}               // 不可被重写

static int count;               // 静态：属于类，不属于实例
static void helper() {}         // 通过类名调用：ClassName.helper()
```

## 6. 构造顺序

创建子类对象时：先执行父类构造，再执行子类构造。子类构造默认调用父类无参构造（`super()`）。

```java
public class Dog extends Animal {
    public Dog() {
        super();   // 显式调用父类构造（不写则默认）
    }
}
```

## 7. equals 与 hashCode

对象比较语义：

```java
public class Person {
    private String name;
    private int age;

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof Person)) return false;
        Person p = (Person) o;
        return age == p.age && name.equals(p.name);
    }

    @Override
    public int hashCode() {      // 重写 equals 必须重写 hashCode
        return Objects.hash(name, age);
    }
}
```

**规则**：重写 `equals` 必须重写 `hashCode`，否则在 `HashMap`/`HashSet` 中行为错误。
