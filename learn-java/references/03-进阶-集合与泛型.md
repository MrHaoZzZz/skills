# Java 进阶 · 集合框架与泛型

## 1. 集合框架（Collections Framework）

Java 集合是日常开发最常用的数据结构，统一在 `java.util` 包。两大接口：**Collection** 和 **Map**。

```
Collection
 ├── List     （有序、可重复）
 │     ├── ArrayList    （动态数组，随机访问快）
 │     └── LinkedList   （双向链表，增删快）
 ├── Set      （无序、不重复）
 │     ├── HashSet      （哈希，O(1)）
 │     ├── LinkedHashSet（哈希+链表，保插入序）
 │     └── TreeSet      （红黑树，有序）
 └── Queue / Deque（队列/双端队列）

Map  （键值对）
 ├── HashMap           （哈希，O(1)）
 ├── LinkedHashMap     （保插入序）
 └── TreeMap           （按键有序）
```

### 常用操作

```java
import java.util.*;

// List
List<String> list = new ArrayList<>();
list.add("a");
list.add("b");
list.get(0);                    // "a"
list.set(0, "x");               // 修改
list.remove(0);                 // 删除
int size = list.size();
for (String s : list) { ... }   // 遍历

// Set
Set<Integer> set = new HashSet<>();
set.add(1);
set.add(1);                     // 重复，不会添加
boolean has = set.contains(1);

// Map
Map<String, Integer> map = new HashMap<>();
map.put("alice", 30);
int age = map.get("alice");              // 30（key 不存在返回 null）
int age2 = map.getOrDefault("bob", 0);   // 安全取
for (Map.Entry<String, Integer> e : map.entrySet()) {
    System.out.println(e.getKey() + "=" + e.getValue());
}
```

**选用原则**：
- 有顺序、可重复 → `ArrayList`
- 去重、无序 → `HashSet`
- 键值对快速查找 → `HashMap`
- 需要有序遍历 → `TreeMap`/`TreeSet`

## 2. 泛型（Generics）

泛型让代码在**编译期**做类型检查，避免 `ClassCastException` 和显式转型。

```java
// 没有泛型（旧写法，危险）
List list = new ArrayList();
list.add("hello");
String s = (String) list.get(0);   // 需手动转型，易错

// 泛型（推荐）
List<String> list2 = new ArrayList<>();
list2.add("hello");
String s2 = list2.get(0);          // 编译期保证类型安全
```

### 泛型方法

```java
public static <T> T first(List<T> list) {
    return list.get(0);
}
```

### 通配符与边界

```java
// ? extends T：T 或 T 的子类（生产者：读）
void readOnly(List<? extends Number> nums) {
    for (Number n : nums) { ... }
}

// ? super T：T 或 T 的父类（消费者：写）
void addIntegers(List<? super Integer> list) {
    list.add(1);
}

// 记忆口诀：PECS —— Producer Extends, Consumer Super
```

### 泛型擦除（type erasure）

重要概念：Java 泛型在**编译后会被擦除**，运行时不存在泛型类型信息。所以：

```java
List<String> 和 List<Integer> 在运行时是同一个类型 List（字节码相同）
// 因此不能 new T()、不能用 instanceof 检查泛型参数
```

## 3. 异常（Exception）

异常体系：

```
Throwable
 ├── Error          （系统级错误，一般不处理，如 OutOfMemoryError）
 └── Exception
      ├── RuntimeException（非受检异常，如 NullPointerException）
      └── 其他（受检异常 checked，必须处理，如 IOException）
```

### 捕获与抛出

```java
// 捕获
try {
    int n = Integer.parseInt(str);   // 可能抛 NumberFormatException
} catch (NumberFormatException e) {
    System.out.println("not a number");
} finally {
    // 无论是否异常都执行（释放资源）
}

// try-with-resources（Java 7+，自动关闭资源，推荐）
try (BufferedReader br = new BufferedReader(new FileReader("f.txt"))) {
    String line = br.readLine();
} catch (IOException e) {
    e.printStackTrace();
}

// 抛出
public void check(int age) throws IllegalArgumentException {
    if (age < 0) throw new IllegalArgumentException("age must >= 0");
}
```

**关键点**：
- 受检异常（checked）必须 try-catch 或 `throws` 声明。
- `finally` 恒执行（即使有 return）。
- 优先用 try-with-resources 管理资源。
- 不要用异常做正常流程控制。

## 4. 枚举（enum）

```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY;

    public boolean isWeekend() { return this == SATURDAY; }  // 枚举可有方法
}

Day d = Day.MONDAY;
switch (d) { case MONDAY -> System.out.println("start"); }
for (Day day : Day.values()) { ... }   // 遍历所有值
```
