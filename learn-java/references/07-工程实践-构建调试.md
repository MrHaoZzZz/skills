# Java 工程实践 · 构建、打包与调试

## 1. 构建工具：Maven 与 Gradle

单文件可用 `javac`/`java`，真实项目必须用构建工具管理依赖、编译、测试、打包。

### Maven（XML 配置，最常见）

项目结构约定：

```
myproject/
  pom.xml
  src/
    main/java/com/example/App.java
    main/resources/
    test/java/com/example/AppTest.java
```

`pom.xml` 核心：

```xml
<project>
  <modelVersion>4.0.0</modelVersion>
  <groupId>com.example</groupId>
  <artifactId>myapp</artifactId>
  <version>1.0.0</version>

  <properties>
    <maven.compiler.source>17</maven.compiler.source>
    <maven.compiler.target>17</maven.compiler.target>
  </properties>

  <dependencies>
    <dependency>
      <groupId>org.junit.jupiter</groupId>
      <artifactId>junit-jupiter</artifactId>
      <version>5.10.0</version>
      <scope>test</scope>
    </dependency>
  </dependencies>
</project>
```

常用命令：

```bash
mvn compile        # 编译
mvn test           # 运行测试
mvn package        # 打包成 jar
mvn clean          # 清理
```

### Gradle（Groovy/Kotlin DSL，更现代）

```groovy
plugins {
    id 'java'
}
repositories { mavenCentral() }
dependencies {
    testImplementation 'org.junit.jupiter:junit-jupiter:5.10.0'
}
```

```bash
gradle build
gradle test
```

## 2. 打包与运行

```bash
# 普通 jar（不含依赖）
mvn package
java -cp target/myapp-1.0.0.jar com.example.App

# 可执行 fat jar（含所有依赖），需在 pom 配置 maven-shade-plugin 或 spring-boot 插件
java -jar myapp-1.0.0.jar
```

## 3. 单元测试（JUnit）

```java
import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class CalculatorTest {
    @Test
    void testAdd() {
        Calculator c = new Calculator();
        assertEquals(5, c.add(2, 3));
    }

    @Test
    void testDivideByZeroThrows() {
        Calculator c = new Calculator();
        assertThrows(ArithmeticException.class, () -> c.divide(1, 0));
    }
}
```

**价值**：你已有算法底子，测试意识是工程化的关键一步——每个边界、每个异常分支都该有测试。

## 4. 调试

### IDE 断点调试
在 IntelliJ IDEA / Eclipse 中打断点、单步（Step Over/Into）、看变量、条件断点。

### 命令行 jdb（基本流程）

```bash
jdb -classpath target/classes com.example.App
> stop in com.example.App.main   # 断点
> run
> next
> print var
> list
> cont
```

### JVM 工具

```bash
jps        # 列出 Java 进程
jstack PID # 线程栈（排查死锁）
jmap PID   # 堆内存
jstat -gc PID  # GC 统计
```

## 5. 编码规范与最佳实践

- **命名**：类 `PascalCase`，方法/变量 `camelCase`，常量 `UPPER_SNAKE_CASE`。
- **单一职责**：类和方法都只做一件事。
- **面向接口编程**：依赖抽象而非具体实现（利于测试和替换）。
- **不可变优先**：能 `final` 就 `final`，用 `record`（Java 16+）定义纯数据类。
- **日志**：用 SLF4J + Logback，别用 `System.out.println` 打日志。
- **异常**：不吞异常、不打印后返回、不用异常控制流程。
- **空安全**：优先返回 `Optional`，用 `Objects.requireNonNull` 校验入参。
- **代码检查**：SpotBugs、Checkstyle、SonarQube。

### record（现代数据类）

```java
public record Person(String name, int age) {}   // 自动生成构造器/getter/equals/hashCode
```
