# Java 高级 · 多线程与并发

## 1. 线程基础

Java 中创建线程有两种方式：继承 `Thread` 或实现 `Runnable`（推荐后者，更灵活）。

```java
// 推荐：实现 Runnable
class Task implements Runnable {
    @Override
    public void run() {
        System.out.println(Thread.currentThread().getName());
    }
}

Thread t = new Thread(new Task());
t.start();        // 启动线程（不是 run()！）
t.join();         // 等待结束
```

**易错点**：`start()` 才会创建新线程；直接调 `run()` 只是普通方法调用。

## 2. 线程池（ThreadPoolExecutor）

手动 `new Thread` 代价高，生产环境一律用线程池。

```java
import java.util.concurrent.*;

ExecutorService pool = Executors.newFixedThreadPool(10);   // 固定大小线程池

for (int i = 0; i < 100; i++) {
    int taskId = i;
    pool.submit(() -> System.out.println(taskId));        // 提交任务
}

pool.shutdown();            // 不再接受新任务，执行完关闭
pool.awaitTermination(1, TimeUnit.MINUTES);
```

### 常见线程池

| 方法 | 特点 |
|------|------|
| `newFixedThreadPool(n)` | 固定线程数 |
| `newCachedThreadPool()` | 按需伸缩 |
| `newSingleThreadExecutor()` | 单线程串行 |
| `newScheduledThreadPool(n)` | 定时/周期任务 |

> 生产环境更推荐 `ThreadPoolExecutor` 显式构造，精确控制队列和拒绝策略。

## 3. 线程安全与同步

### synchronized（内置锁）

```java
public class Counter {
    private int count = 0;

    public synchronized void increment() {   // 同步方法，锁当前对象
        count++;
    }
}

// 或同步代码块（更细粒度）
synchronized (lock) { ... }
```

### volatile（可见性）

```java
volatile boolean running = true;
// 保证变量修改对其他线程立即可见，但不保证复合操作的原子性
```

**关键区分**：
- `synchronized`：保证**原子性 + 可见性**。
- `volatile`：只保证**可见性**，不保证 `count++` 这种读-改-写的原子性。

### Lock 与原子类

```java
import java.util.concurrent.locks.ReentrantLock;
import java.util.concurrent.atomic.AtomicInteger;

ReentrantLock lock = new ReentrantLock();
lock.lock();
try { ... } finally { lock.unlock(); }   // 必须 finally 解锁

AtomicInteger ai = new AtomicInteger(0);
ai.incrementAndGet();   // 原子自增，无需锁
```

## 4. 并发集合

```java
// 线程安全的 Map
ConcurrentHashMap<String, Integer> map = new ConcurrentHashMap<>();

// 线程安全的 List
CopyOnWriteArrayList<Integer> list = new CopyOnWriteArrayList<>();

// 用 Collections 包装（旧方案，性能一般）
List<Integer> syncList = Collections.synchronizedList(new ArrayList<>());
```

**规则**：多线程共享集合时用并发集合，不要用普通 `HashMap`/`ArrayList`（会数据竞争）。

## 5. CompletableFuture（异步编程）

现代 Java 的异步利器，比裸线程/Future 好用得多。

```java
CompletableFuture.supplyAsync(() -> fetchData())        // 异步执行
    .thenApply(data -> process(data))                   // 结果转换
    .thenAccept(result -> save(result))                 // 消费结果
    .exceptionally(e -> { log(e); return null; });      // 异常处理

// 组合多个异步任务
CompletableFuture<String> f1 = ...;
CompletableFuture<Integer> f2 = ...;
f1.thenCombine(f2, (s, i) -> s + i);   // 等两个都完成再组合
```
